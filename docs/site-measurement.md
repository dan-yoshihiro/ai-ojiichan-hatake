# このサイトの測定方針 — 読まれたか、役立ったかをどう見るか

*公開: 2026-08-12*

> **TL;DR**: このサイトはPVだけで成果を判断しない。Xの運用データ、サイト内の正規コンテンツ閲覧、検索で使われたクエリを分けて観測し、どの記事が誰に役立ったかを判断する。

## 3つの層で見る

| 層 | 主な確認項目 | 判断したいこと |
|---|---|---|
| X運用 | 投稿型・リプ・保存・引用・フォロワー増減 | 何が読者に届いたか |
| サイト閲覧 | 正規コンテンツの閲覧・参照元・読まれた記事 | どの記録に関心が集まったか |
| 検索 | 検索クエリ・表示回数・クリック・流入ページ | どんな悩みで見つけられたか |

## 数字の読み違いを避ける

アクセス数にはAI botやscannerが混ざる。そのため、正規コンテンツの閲覧と、それ以外の機械アクセスを分けて見る。記事の価値をPVだけで決めず、実測の更新後に読まれたか、次の記事へ進まれたか、検索でどんな悩みに対応できたかを合わせて確認する。

## 月に一度、見ること

1. 検索で表示されたクエリと、クリックされた記事を確認する
2. 表示はあるがクリックされない記事のタイトルと冒頭を見直す
3. Xから来た人が、主力記事まで進めているかを確認する
4. 新しい一次データがある場合だけ、月次ログまたは既存記事を更新する

検索データが十分にたまるまでは、無理に検索向けの記事を量産しない。実際の運用ログから、読者が持ち帰れる判断材料が増えたときに更新する。
