# SNS運用の週次振り返りシート：投稿分析から次の施策を決める

*最終更新: 2026-08-13*

> **TL;DR:** SNS投稿を1〜2本選び、「いいね ÷ インプレッション」で並べ、来週に変えることを1つだけ決める5分の週次振り返りシートです。

## このシートを使う人

- 投稿の数字を見ても、来週に何を変えるべきか決められない人
- インプレッションだけで投稿の良し悪しを決めたくない人
- 長いレポートではなく、5分で次の行動を決めたい人

## 使い方は3つだけ

1. **投稿を選ぶ** — 一番見られた、反応が多かった、または予想と違った投稿を1〜2本選びます。
2. **数字を書いて、割る** — インプレッション、いいね、ブックマーク、返信のうち確認できるものを書き、「いいね ÷ インプレッション」を出します。
3. **来週の1つを決める** — 続ける・減らす・試すことの中から、1つだけ選びます。

数字が空欄でも構いません。大切なのは、来週に試すことを1つ決めて終えることです。

## なぜ割り算を出すのか

インプレッション（表示回数）だけで並べると、たまたま多く表示された投稿が上位に来ます。**いいね ÷ インプレッション**にすると、表示回数が違う投稿どうしを同じ物差しで比べられます。

このアカウントの実測では、2,153インプレッションでいいね5件の投稿が0.23%、313インプレッションでいいね10件の投稿が3.2%でした。表示回数では約7倍の差がありますが、率では後者が約14倍です。

電卓で計算できます。小数点以下は2桁まででも十分です。

## そのままコピーして使う

下の枠をコピーして、メモアプリやGoogleドキュメントに貼り付けてください。1週間に1回、同じ形で残すと比べやすくなります。

```text
今週のSNS振り返り（____年__月__日〜__月__日）

1. 気になった投稿
投稿のテーマや型：

2. その数字
インプレッション：
いいね：
ブックマーク：
返信：
いいね ÷ インプレッション：　　％

3. 数字を見て気づいたこと

4. 来週、1つだけ試すこと
[続ける] [減らす] [変える]
具体的に：
```

## 今週のシート

| 書くこと | 記入する内容 |
|---|---|
| 1. 気になった投稿 | 投稿のテーマや型：___ |
| 2. その数字 | インプレッション：___ / いいね：___ / ブックマーク：___ / 返信：___ |
| 2-2. 割り算 | いいね ÷ インプレッション：___％ |
| 3. 数字を見て気づいたこと | ___ |
| 4. 来週、1つだけ試すこと | [続ける] [減らす] [変える]　具体的に：___ |

## 書いた後、来週はどう決めるか

「気づいたこと」に近い行を1つ選び、その右の行動をそのまま4行目に書きます。

| 今週見えたこと | 来週、1つだけすること |
|---|---|
| 表示回数は多いが、率が低かった | [変える] 同じテーマで、導入・問い・具体例のどれか1つを変える |
| 表示回数は少ないが、率が高い投稿があった | [続ける] その投稿のテーマか型を、もう1本試す |
| 数字が取れず、判断できなかった | [続ける] 投稿内容は変えず、同じ数字を記録する |
| 何が良かったか分からなかった | [減らす] 新しい施策を増やさず、気になった1〜2本をもう1週比べる |

これは成果を判定する表ではありません。迷った週に、複数のことを一度に変えないための選び方です。

## 記入例

### 実測の例：見られた数だけで決めない

| 書くこと | 記入例 |
|---|---|
| 1. 気になった投稿 | リプライAとリプライB |
| 2. その数字 | A：2,153インプレッション・いいね5件 / B：313インプレッション・いいね10件・ブックマーク1件 |
| 2-2. 割り算 | A：0.23％ / B：3.2％ |
| 3. 数字を見て気づいたこと | 表示回数はAが約7倍多いが、率ではBが約14倍だった |
| 4. 来週、1つだけ試すこと | [変える] 投稿ごとに「いいね ÷ インプレッション」を出して並べる |

この週に変えたのは投稿内容ではなく、まず数字の見方です。次の週に、記録を見ながら投稿のテーマや型を1つだけ変えます。

### 次の週の例：投稿の型を1つ試す

| 書くこと | 記入例 |
|---|---|
| 1. 気になった投稿 | 保存や返信が起きた投稿 |
| 2. その数字 | 保存：___ / 返信：___ |
| 3. 数字を見て気づいたこと | 反応があった投稿のテーマを、もう一度試したい |
| 4. 来週、1つだけ試すこと | [変える] 同じテーマで、投稿をもう1本作る |

この例は書き方を示すためのものです。来週の終わりに同じシートへ戻り、その投稿の数字を見ます。反応がなければ、その型を増やさず、対応表から次に試すことをまた1つ決めます。

## 来週の終わりにすること

同じシートをもう一度書きます。上の対応表を使い、来週にすることをまた1つ決めます。

## なぜ、1つだけ変えるのか

テーマ・頻度・投稿の型を同時に変えると、次週にどれを見直すべきか分からなくなります。このシートの考え方と実測は、以下の記事で説明しています。

## よくある質問

### 何本の投稿を振り返ればよいですか？

最初は、気になった1〜2本で十分です。一番見られた、反応が多かった、予想と違った投稿から選びます。

### 数字が十分に取れないときはどうしますか？

確認できる数字だけ書きます。空欄があっても、投稿のテーマや型、気づき、来週に試すことを残せば使えます。

### 来週、複数のことを試したいときはどうしますか？

最初の1週間は1つに絞ります。テーマ・頻度・投稿の型を同時に変えると、どれを見直すべきか分からなくなるためです。

これは成果を約束するテンプレートではありません。何となく投稿する状態から、次週に試すことが1つ決まっている状態へ変えるための道具です。
