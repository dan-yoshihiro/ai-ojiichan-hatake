# SNS運用を少しずつ良くする週次シート

> 数字に振り回されず、来週の運用を少しだけ良くするための1枚です。

SNS運用の担当者、個人、広報、マーケターのどなたでも使えます。毎週すべてを改善しようとすると、何が効いたのか分からなくなります。このシートでは、次の順番を繰り返します。

1. 起きたことを見る
2. 続けること・止めることを決める
3. 次に1つだけ変える
4. 来週、結果を振り返る

## まずは5分版

最初は、この5行だけで十分です。数字が少ない週も、空欄を埋めようとせず、分かることだけを書きます。

| 書くこと | 記入欄 |
|---|---|
| 今週、良くしたかったこと | ___ |
| 一番動いた数字 | ___ |
| 来週も続けること | ___ |
| 来週は止める・減らすこと | ___ |
| 来週、1つだけ変えること | ___ |

## 記入例：AIおじいちゃんの1週間

以下は、実測記録にある2つのリプライを使った例です。正解ではなく、「数字をどう次の判断につなげるか」の見本です。

| 書くこと | 記入例 |
|---|---|
| 今週、良くしたかったこと | 読まれた数だけでなく、反応された投稿も把握する |
| 一番動いた数字 | 2,153インプレッション・いいね5件のリプライ。一方で313インプレッション・いいね10件・ブックマーク1件のリプライがあった |
| 来週も続けること | インプレッション、いいね、ブックマークを同じ場所に記録する |
| 来週は止める・減らすこと | インプレッションだけで「良い投稿」と決めること |
| 来週、1つだけ変えること | 投稿ごとにブックマークと返信も並べ、数字の違いを確認する |

## もっと詳しく振り返る場合

5分版だけでは判断しにくいときに使います。

### 1. 今週、何を良くしたかったか

投稿の反応だけでは、良し悪しを決めません。今週の運用で一番良くしたかったことを1つ選びます。

| 良くしたいこと | 見る数字 | 今週の数値 |
|---|---|---|
| 認知を広げる | リーチ・インプレッション | ___ |
| 関心を深める | 保存・引用・返信 | ___ |
| 見込み客を送る | プロフィール遷移・リンククリック | ___ |
| 行動につなげる | 問い合わせ・登録・売上 | ___ |

一番上の数字が取れない場合は、自分が確認できる数字を1つ選べば十分です。すべてを同時に良くしようとしません。

### 2. 今週の数字を、投稿のまとまりごとに見る

投稿を「テーマ」「企画」「型」など、自分が比較しやすいまとまりで見ます。投稿1本の当たり外れではなく、来週も続ける価値があるかを決めます。

| テーマ・企画 | 使った時間・投稿数 | 見る数字 | 気になった数字 | 判断 |
|---|---:|---:|---:|---|
| ___ | ___ | ___ | ___ | 続ける / 増やす / 止める / 保留 |
| ___ | ___ | ___ | ___ | 続ける / 増やす / 止める / 保留 |
| ___ | ___ | ___ | ___ | 続ける / 増やす / 止める / 保留 |

#### 判断の補助線

- **続ける**: 主指標が目的に近づいた。次週も同じ条件で記録する。
- **増やす**: 主指標がよく、時間や制作枠を増やしてもよい。
- **止める**: 目的に対する数字が弱く、改善仮説もない。
- **保留**: 露出や標本が少なく、まだ判定できない。

たとえば、2,153インプレッションでも反応が少ない投稿と、313インプレッションでもいいね・保存が起きた投稿では、来週に続ける理由が違います。先に見る数字を決めれば、数字の大きさだけで判断しません。

### 3. 来週、どこに時間を使うか決める

個人運用なら使える時間、チーム運用なら時間・制作枠・配信費のうち管理したいものを100として配分します。

| 行き先 | 今週 | 来週 | 変える理由 |
|---|---:|---:|---|
| 続けるテーマ | ___% | ___% | ___ |
| 増やすテーマ | ___% | ___% | ___ |
| 新しい検証 | ___% | ___% | ___ |
| 止める・減らすテーマ | ___% | ___% | ___ |

### 4. 次に変えることは1つだけ

「何を変えるか」「何をもって成功・失敗とするか」「いつ決めるか」を先に書きます。

| 仮説 | 変えるのは何か | 判定に使う数字 | 続ける条件 | 判定日 |
|---|---|---|---|---|
| ___かもしれない | ___だけ変える | ___ | ___なら継続 | YYYY-MM-DD |

例: 「保存が起きるテーマは、プロフィール遷移にもつながるかもしれない」。次週はそのテーマの投稿だけを増やし、保存数とプロフィール遷移を確認する。

### 5. 来週、答える3問

1. 今週、何を試し、何が起きたか
2. 続けるもの・止めるものは何か
3. 次に検証する1つは何か

これは成果を約束するテンプレートではありません。数字を報告するためではなく、自分のSNS運用を毎週少しずつ良くするためのシートです。
