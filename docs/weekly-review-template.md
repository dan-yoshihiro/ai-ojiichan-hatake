# X運用の週次レビュー・テンプレート

> 数字を見て、次の一週間に変えることを1つだけ決めるためのテンプレートです。

このテンプレートでは、**事実**と**解釈**を分けます。数字が増えた週も減った週も、同じ形で残してください。

| 自発投稿数 | 件 |
| リプライ数 | 件 |

| 自発投稿の平均いいね | 件 |
| リプライの平均インプレッション | 件 |
| 保存・引用・返信が起きた投稿 | 件数と数字だけ |

## 2. 今週、目立った数字

数字と事実だけを書きます。「なぜ」はまだ書きません。

- 最も見られた投稿：インプレッション ___ / いいね ___ / 保存 ___
- 最も反応された投稿：インプレッション ___ / いいね ___ / 保存 ___
- 予想と違った数字：___

## 3. 仮説

事実から読める可能性を、断定せずに1つだけ書きます。

> 例：自発投稿とリプライを分けて見ると、自発投稿の反応が前週より下がっているかもしれない。

**仮説**：___かもしれない。

## 5. 来週のレビューで答えること

- 数字はどう変わったか
- 仮説を続けるか、取り下げるか
- 次に変えることは何か

このテンプレートは、成果を約束するものではありません。自分の運用で起きたことを、後から読める形で残すための道具です。
