# SNS運用を少しずつ良くする週次シート

> 数字に振り回されず、来週の運用を少しだけ良くするためのシートです。

SNS運用の担当者、個人、広報、マーケターのどなたでも使えます。毎週すべてを改善しようとすると、何が効いたのか分からなくなります。

このシートでやることは4つです。

1. 今週起きたことを見る
2. 続けること・止めることを決める
3. 来週1つだけ変える
4. 来週、その結果を振り返る

## まずは5分版

最初はこの5行だけで十分です。数字が少ない週は、分かる数字だけを書きます。

| 書くこと | 何を書くか | 記入欄 |
|---|---|---|
| 今週、良くしたかったこと | 例：より多くの人に見てもらう／返信を増やす／記事へ来てもらう | ___ |
| 一番動いた数字 | 一番大きかった、または意外だった数字を1つ | ___ |
| 来週も続けること | 目的に近づいた投稿・テーマ・作業を1つ | ___ |
| 来週は止める・減らすこと | 目的に近づかず、直す案もない作業を1つ | ___ |
| 来週、1つだけ変えること | 投稿テーマ・頻度・導線など、変えることを1つ | ___ |

## 記入例：AIおじいちゃんの1週間

以下は、実測記録にある2つのリプライを使った例です。正解ではなく、数字を次の判断につなげる書き方の見本です。

| 書くこと | 記入例 |
|---|---|
| 今週、良くしたかったこと | 読まれた数だけでなく、反応された投稿も把握する |
| 一番動いた数字 | 2,153インプレッション・いいね5件のリプライ。一方で313インプレッション・いいね10件・ブックマーク1件のリプライがあった |
| 来週も続けること | インプレッション、いいね、ブックマークを同じ場所に記録する |
| 来週は止める・減らすこと | インプレッションだけで「良い投稿」と決めること |
| 来週、1つだけ変えること | 投稿ごとにブックマークと返信も並べ、数字の違いを確認する |

ここまで書けたら、来週はこの5行を見返すだけで十分です。

## もっと詳しく振り返る場合

5分版だけでは「どれを続けるか」決めにくい週に使います。すべての欄を埋める必要はありません。

### 1. 目的と数字を1つだけ結ぶ

まず、今週一番良くしたかったことと、それを確認する数字を1つ選びます。複数の数字を追いたくなっても、主役は1つにします。

| 良くしたいこと | まず見る数字 | 記入例 |
|---|---|---|
| より多くの人に見てもらう | インプレッションまたはリーチ | インプレッション 3,000 |
| 読んだ人の関心を深める | 保存・引用・返信のいずれか | 保存 12件 |
| プロフィールや記事へ来てもらう | プロフィール遷移またはリンククリック | リンククリック 24件 |
| 問い合わせや登録につなげる | 問い合わせ・登録・売上のいずれか | 登録 3件 |

**今週の目的**：___

**見る数字**：___

**今週の数値**：___

### 2. 投稿を2〜3つのまとまりで比べる

「テーマ」「企画」「投稿の型」など、あとで見分けられる名前を付けます。1投稿ごとではなく、同じ目的の投稿をまとめます。

| まとまりの名前 | 何を投稿したか | 投稿数 | 見る数字 | 判断 |
|---|---|---:|---:|---|
| 例：栽培の気づき | 写真＋短い気づき | 3 | 保存 5件 | 続ける |
| 例：質問への返信 | 他者の質問へリプライ | 8 | 返信 2件 | 保留 |
| ___ | ___ | ___ | ___ | 続ける / 増やす / 止める / 保留 |

判断は次の基準で選びます。

- **続ける**: 今週の目的に少しでも近づいた。来週も同じ形で記録する。
- **増やす**: 目的に近づき、無理なく投稿数や時間を増やせる。
- **止める**: 目的に近づかず、次に試す改善案もない。
- **保留**: 投稿数・露出が少なく、まだ決められない。

数字の大きさだけで決めません。2,153インプレッションでも反応が少ない投稿と、313インプレッションでもいいね・保存が起きた投稿では、続ける理由が異なります。

### 3. 来週やることを3つに絞る

時間を%で配分しなくても大丈夫です。実際にやることを、継続・停止・検証の3つだけ書きます。

| 種類 | 来週やること | いつやるか | なぜやるか |
|---|---|---|---|
| 続ける | ___ | ___ | 今週の目的に近づいたため |
| 止める・減らす | ___ | ___ | 目的に近づかず、改善案もないため |
| 1つだけ検証する | ___ | ___ | 数字の違いを確かめるため |

チームで時間・制作枠・配信費を管理する場合だけ、この3つにどれだけ配分するかを追記します。

### 4. 検証の終わりを先に決める

「何を変えるか」だけでなく、いつ・どの数字を見て続けるかを先に書きます。

| 書くこと | 何を書くか | 記入欄 |
|---|---|---|
| 仮説 | 「___すると、___が増えるかもしれない」の形 | ___ |
| 変えること | テーマ・頻度・導線など、1つだけ | ___ |
| 見る数字 | 1で決めた主役の数字 | ___ |
| 続ける条件 | 例：保存が前週より増えたら継続 | ___ |
| 判定日 | 次に見返す日 | YYYY-MM-DD |

### 5. 来週、答える3問

1. 今週、何を試し、何が起きたか
2. 続けるもの・止めるものは何か
3. 次に検証する1つは何か

このシートは成果を約束するものではありません。数字を報告するためではなく、自分のSNS運用を毎週少しずつ良くするための道具です。
