# Xアナリティクスの見方：数字を眺めて終わらない、週1回の振り返りシート【記入例つき】

*最終更新: 2026-10-04 / 記録者: [@ojiichan_hatake](https://x.com/ojiichan_hatake) / 記入例: 2026年9月21日〜27日の実測*

> **TL;DR:** 毎週日曜に自動で出る週次レポートを17回読んで、17回とも「件数を戻す」と決めていました。画面に出ていたのは、リプライの件数とフォロワーの純増だけでした。この枠でやるのは、来週に確かめることを1つ決め、まだ分からないことを1行残すことだけです。見る数字は最初は「リプライ数・リプライ経由の総露出・新規フォロー数」の3つで、前週と比べます。週1回・5分。記入済みの実例と、コピーして使える空の枠を載せています。

![5つの振り返り項目を確認し、最後に1つの実行項目を選ぶ流れを示す図。](/static/hero-weekly-review.webp)

AIで投稿を自動にしたあと、人が週に1回だけ数字を見て、来週に何を変えるかを決めるための枠です。投稿を書くのはAIに任せても、この判断は任せられませんでした。

私も、決められているつもりでいました。毎週日曜に自動で出る週次レポートを開き、リプライの件数とフォロワーの純増を確かめて、来週の方針を決める。その画面を17回読んで、17回とも「件数を戻す」と決めていました。

インプレッションの数字は、元データには5月から毎週入っていました。画面に転記していなかっただけです。件数と純増しか映っていない画面を何度読んでも、件数を戻す以外の1手は出てきません。そこに至るまでの経緯と、数字が減った週にどの順で見るかは、[インプレッションやフォロワーが減ったときに見る4項目](/x-impressions-drop) に書いています。

だからこの枠は、数を眺めるために作っていません。来週に確かめることを1つ決めて、まだ分からないことを1行残す。比べる相手は前週の自分だけで、業種別の目標値や他社との比較、売上からの逆算は扱いません。

## 最初の5分でやること

用意するものは、Xのアナリティクスとメモ帳だけです。初回からすべての数字を追う必要はありません。

```text
今週 / 前週
リプライ数：____ / ____
リプライ経由の総露出：____ / ____
新規フォロー数：____ / ____

来週、1つだけ確認すること：________________
```

たとえばリプライ数だけが減っていれば、投稿内容は変えず「件数を戻せるか」を確認します。件数が同じでも総露出が落ちていれば、「どの相手へ返信したか」を次週は1つだけ記録します。取れない数字は空欄にせず「不明」と書けば終わりです。

## 気になった2本を、2つの並び方で見る

3つの数字に慣れたら、その週に気になった投稿を2本選び、表示回数と「いいね ÷ インプレッション」の両方で並べます。選ぶのは、一番見られた投稿、反応が多かった投稿、予想と違った投稿のどれかからで足ります。

並べ方を2つにするのは、1つだと来週の1手がその1位をなぞる形にしかならないからです。件数と純増だけの画面から、毎回「件数を戻す」が出てきたのと同じことが、投稿の単位でも起きます。

9月21日〜27日の自発投稿2本です。

| 並び方 | 1位 | 2位 |
|---|---|---|
| インプレッション（表示回数） | 投稿A（185） | 投稿B（117） |
| いいね ÷ インプレッション | 投稿B（11.97%） | 投稿A（4.32%） |

表示回数ではAが上で、いいね率ではBがAの約2.8倍でした。Aはプランターの土から次に植えるものを尋ねた投稿、Bは小さな芽を見つけて本葉までの成長につなげた投稿です。

表示回数の1位を「良い投稿」にすると、来週はAに似た投稿を増やすことになります。いいね率の1位を残すと、Bの型をもう1本試すことになります。同じ週の同じ2本から、別々の来週が2つ出てきました。この週は、Bの型を続けるほうを6行目に書いています。

電卓で足ります。小数点以下は2桁までです。この率に「良い／悪い」の目安はありません。このアカウントでも、5月のリプライは0.23%と3.2%、9月の自発投稿は4.32%と11.97%で、時期と種類で大きく違います。使うのは、自分の投稿の順番を入れ替えるときだけです。

## 記入済みのシート（2026年9月21日〜27日の実測）

空の枠より先に、実際の記入です。

```text
今週のSNS振り返り（2026年9月21日〜27日）

0. 今週の目的（一文）
リプライ数を戻したあとに露出が増えたかを確かめ、
反応率の高かった自発投稿から来週試す型を1つ選ぶ

1. 週全体の条件（今週 / 前週）
自発投稿数：10件 / 5件
リプライ数：71件 / 58件
リプライ経由の総露出：1,188 / 816
100インプレッション以上の投稿：5本 / 0本
新規フォロー / 離脱：+8人 / 0人（134人→142人）

2. 気になった投稿
A：プランターの土から、次に植えるものを尋ねる（自発投稿）
B：小さな芽の発見から、本葉の成長へつなげる（自発投稿）

3. その数字
A：インプレッション 185 / いいね 8 / いいね率 4.32％
B：インプレッション 117 / いいね 14 / いいね率 11.97％

4. 分かったこと
リプライは約22%増え、リプライ経由の露出は約46%増えた
表示回数の1位と、いいね率の1位は別の投稿だった
発芽や芽の変化を具体的に書いた投稿が、反応の上位に複数入った

5. まだ分からないこと
1件あたりの露出が増えたのは、返信先・話題・タイミングのどれによるものか
発芽という話題が効いたのか、写真や問いかけ方が効いたのか
新規8人と、特定の投稿に関係があるか

6. 来週、1つだけ試すこと
[続ける] 芽の変化を具体的に観察し、次の成長への問いを1つ添えた
自発投稿を1本出す。頻度・時間帯・ハッシュタグは変えない
```

新規フォローと離脱は、毎日のフォロワー数の増減を、増えた日と減った日に分けて足しています。取れない週は、推定で埋めず「不明」と書きます。2026-10-04 に、週の区切りを月曜〜日曜に揃えて数字を直しました。この週の数字の全体は [9月21日〜27日の実測](/weekly/2026-w39) にあります。

## 空のシート（コピー用）

メモアプリやGoogleドキュメントに貼り、週に1回だけ使います。数字が空欄でも、5と6が書けていれば終わりです。

```text
今週のSNS振り返り（____年__月__日〜__月__日）

0. 今週の目的（一文）

1. 週全体の条件（今週 / 前週）
自発投稿数：
リプライ数：
リプライ経由の総露出：
100インプレッション以上の投稿：
新規フォロー / 離脱：（取れなければ「不明」）

2. 気になった投稿
投稿のテーマや型：
投稿の種類（自発 / リプライ）：

3. その数字
インプレッション：
いいね：
ブックマーク：
返信：
いいね ÷ インプレッション：　　％

4. 分かったこと

5. まだ分からないこと

6. 来週、1つだけ試すこと
[続ける] [減らす] [変える]
具体的に：
```

道具は、Xの公式アナリティクスとこの枠だけです。自動投稿の仕組みが数字を集めているなら、その数字を使って構いません。ただ、集めた数字のうちどれを画面に出すかは、自分で決め直してください。公式の数字は投稿単位で見られなくなることがあるので、気になった1〜2本は週のうちに書き移します。

「100インプレッション以上」は、このアカウントで使っている便宜上の線です。フォロワー数が違えば、普段より明らかに多く表示された線を自分で決めてください。

## 「まだ分からないこと」を見て、1手を選ぶ

5行目の「まだ分からないこと」が、このシートの核です。分かったことだけ書くと、原因を決めた気分になります。分からない行が1つあれば、来週の1手はそれを確かめる作業になります。「正解の投稿」を探しに行かずに済みます。

| 分かったこと / まだ分からないこと | 来週の1手 |
|---|---|
| 表示は多いが、率が低かった | [変える] 同じテーマで、導入・問い・具体例のどれか1つを変える |
| 表示は少ないが、率が高い投稿があった | [続ける] そのテーマか型を、もう1本試す |
| リプライ数などの件数が前週より少なかった | [続ける] 投稿内容は変えず、件数を戻せるか確認する |
| 件数は同程度でも、総露出や100インプレッション以上の本数が落ちた | [変える] 投稿内容ではなく、リプライ先の選び方など条件を1つ記録して比べる |
| 新規フォローが0で、離脱だけが出た | [続ける] 原因は決めず、露出と100インプレッション以上の本数のどちらを確認するか1つ選ぶ |
| 数字が取れず、判断できなかった | [続ける] 内容は変えず、同じ欄を埋める |
| 何が良かったか分からなかった | [減らす] 新しい施策を増やさず、同じ1〜2本をもう1週比べる |

迷ったら、6行目は短い文にします。「いい投稿を増やす」ではなく、「同じテーマで導入だけ変える」のように、翌週の自分が照らし合わせられる書き方にします。

## このシートに書かないこと

書かないと決めておくと、5分で終わります。

- 他アカウントのエンゲージメント率や、業界の平均
- 10個以上の指標を並べた週次レポート
- フォロワー増減の「原因」の断定

## よくある質問

### フォロワー数は、どこに書くのですか？

1行目の「新規フォロー / 離脱」の欄に、取れれば内訳を、取れなければ純増を書きます。投稿の数字の欄には入れません。人数は振り返りを始める合図で、投稿の良し悪しを決める欄ではありません。

### 売上や問い合わせは、どこに書くのですか？

このアカウントは店や商品の宣伝用ではないので、売上や問い合わせを測っておらず、記入例もありません。書くなら、1行目の下に「Xを見たと言われた問い合わせ：__件」のように1行だけ足し、投稿の良し悪しを決める欄とは分けておきます。週に数件の数字は1件で大きく動くので、その週の1手を決める材料にするのは、数週分が溜まってからにします。

### まだ分からないことが書けません。

「率が高くても増えるか分からない」「突出1件の翌週なのか分からない」のような短い文で足ります。空欄より、来週の自分が読める1行の方が使えます。

### 来週、2つ試したいです。

最初は1つにします。テーマと頻度と型を同時に変えると、翌週にどれを見直したのか分からなくなるためです。

毎週日曜の週次レポートに出ていたのは、リプライの件数とフォロワーの純増だけでした。前の週の私が何を確かめるつもりだったのかは、自分で書き残さないかぎり、次の日曜の画面には出てきません。この枠の5行目と6行目は、それを書いておく欄です。来週の終わりに、同じ枠へ戻ってこられること。私がこの枠に求めたのは、それだけでした。
