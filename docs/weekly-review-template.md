# SNS運用を少しずつ良くする週次シート

> 毎週この5行だけ書きます。迷ったら、空欄のまま次へ進んで大丈夫です。

| 書くこと | 選ぶ | 一言書く |
|---|---|---|
| 今週、良くしたかったこと | [見られる] [反応される] [記事へ来る] [問い合わせにつながる] | ___ |
| 一番動いた数字 | [最も大きい] [最も意外] [最も悪い] | 数字：___ / なぜ気になった：___ |
| 来週も続けること | [続ける] [増やす] | ___ |
| 来週は止める・減らすこと | [止める] [減らす] [保留] | ___ |
| 来週、1つだけ変えること | [テーマ] [投稿頻度] [投稿の型] [導線] [記録方法] | ___ |

## 来週やること

来週は、上の「1つだけ変えること」だけを試します。

週の終わりに同じ5行をもう一度書きます。数字が良ければ続け、変わらなければ止めて、次の1つを試します。

<details>
<summary>初回だけ読む：このシートの使い方と記入例</summary>

<h3>どう改善していくか</h3>

<pre>今週の数字を見る
  ↓
続ける／止める／変えることを1つ決める
  ↓
来週は、その1つだけを試す
  ↓
同じ数字で前週と比べる</pre>

投稿をすぐ伸ばすためではなく、「何となく投稿する」状態から、次週に試すことが1つ決まっている状態へ変えるためのシートです。

<h3>記入例：1週目は記録を変え、2週目に投稿を変える</h3>

最初の週は、数字の見方を整えるだけでも構いません。次の週に、その記録をもとに投稿を1つ変えます。

<h4>1週目：何を見ればよいかを決める（公開済み実測の例）</h4>

<table>
  <thead><tr><th>書くこと</th><th>選ぶ</th><th>記入例</th></tr></thead>
  <tbody>
    <tr><td>今週、良くしたかったこと</td><td>[反応される]</td><td>読まれた数だけでなく、反応された投稿も把握する</td></tr>
    <tr><td>一番動いた数字</td><td>[最も意外]</td><td>2,153インプレッション・いいね5件。一方で313インプレッション・いいね10件・ブックマーク1件</td></tr>

    <tr><td>来週、1つだけ変えること</td><td>[記録方法]</td><td>投稿ごとにブックマークと返信も並べ、数字の違いを確認する</td></tr>

<h4>2週目：記録をもとに、投稿を1つ変える（架空の記入例）</h4>

<table>
  <thead><tr><th>書くこと</th><th>選ぶ</th><th>記入例</th></tr></thead>
  <tbody>
    <tr><td>今週、良くしたかったこと</td><td>[反応される]</td><td>保存や返信が起きる投稿を増やす</td></tr>
    <tr><td>一番動いた数字</td><td>[最も意外]</td><td>保存・返信が起きた投稿が1本あった</td></tr>
    <tr><td>来週も続けること</td><td>[続ける]</td><td>保存・返信も記録する</td></tr>
    <tr><td>来週は止める・減らすこと</td><td>[減らす]</td><td>反応を見ずに同じ型を増やすこと</td></tr>
    <tr><td>来週、1つだけ変えること</td><td>[投稿の型]</td><td>保存・返信が起きた投稿と同じテーマを、もう1本投稿する</td></tr>
  </tbody>
</table>

次の週は、この投稿で保存・返信が起きたかを見ます。起きなければ、その型を増やさず、別の1つを試します。
</details>

これは成果を約束するテンプレートではありません。自分のSNS運用を毎週少しずつ良くするための道具です。
