# フォロワー1人だったAIおじいちゃんが、100人に届くまで

*公開: 2026-06-21 / 観測開始: 2026-04-04 / 100人到達: 2026-06-19 / 最新記録: 2026-08-12（129人）*

> 2026年4月4日、フォロワーは1人でした。
>
> 6月19日、100人になりました。

AIに固定ペルソナを与えてXを運用する実験です。このページは成功法則を教える記事ではありません。1人から始まった数字が、止まり、動き、また下がった記録です。

## 最初の15日間、数字は10だった

4月4日に1人だったフォロワー数は、4月19日に10人になりました。

当初は「1ヶ月で100人」を目標にしていました。しかし、15日経っても10人です。そこで、目標を5月末までの50人へ変更しました。

目標を変えたことが、その後の増加を生んだとは言えません。ただ、数字と目標の距離を見て、目標をそのまま信じ続けないという判断は残りました。

## ゴールデンウィーク、数字が続けて動いた

5月に入ると、数字は短い間隔で変わりました。

| 日付 | フォロワー数 |
|---|---:|
| 5月1日 | 18 |
| 5月3日 | 21 |
| 5月4日 | 28 |
| 5月5日 | 31 |
| 5月6日 | 38 |
| 5月10日 | 46 |
| 5月11日 | 51 |

開始から37日目、見直した目標だった50人を超えました。

この時期、運用者が見るようになったのは、フォロワー数だけではありません。投稿が見られた回数と、反応された回数は別の数字でした。

たとえば、あるリプライは **2,153回** 見られ、いいねは **5件**。別のリプライは **313回** 見られ、いいねは **10件**、ブックマークは **1件**でした。

どちらが「良い投稿」だったかは、この数字だけでは決められません。ただし、見られた数だけを成功と呼ばないことは、この時点で決めました。

## 99人から、95人へ戻った

6月12日、フォロワーは99人でした。

翌日は97人。6月16日には95人まで下がりました。100人は、近づけば自動的に通り過ぎる線ではありませんでした。

| 日付 | フォロワー数 |
|---|---:|
| 6月12日 | 99 |
| 6月13日 | 97 |
| 6月16日 | 95 |
| 6月18日 | 97 |
| 6月19日 | 100 |

6月19日、初めて100人に届きました。

![フォロワー1人から129人までの実測推移。](/static/growth-curve.svg)

## 100人を超えても、物語は終わらなかった

7月17日には126人になりました。けれど8月1日には123人へ下がり、8月12日に129人になりました。

数字は上がる日だけではありません。だから、毎週の記録では「増えたか」だけを見ず、何をしたかと、どの数字が動いたかを同じ場所に残すことにしました。

5月17日までの週は、82件の投稿のうち71件がリプライ、11件が自発投稿でした。リプライと自発投稿を同じ平均に混ぜると、自発投稿だけの変化が読めなくなります。以後は、投稿の種類ごとに分けて見ることにしました。
