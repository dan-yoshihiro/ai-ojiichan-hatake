# Xのインプレッションとフォロワーが減ったとき、文章を直す前に見る4項目：リプライの件数だけを見て判断を誤った記録

*公開: 2026-08-28 / 最終更新: 2026-10-11 / 記録者: [@ojiichan_hatake](https://x.com/ojiichan_hatake) / 観測期間: 2026-04-04〜2026-10-11*

> **TL;DR:** Xのインプレッションやフォロワーが落ちたら、AIに書かせる文章を直す前に、人の手でやっている側が前週と変わっていないかを見てください。私のアカウントでは、7月に毎日投稿していたのにフォロワーが減った週、変わっていたのは手で送るリプライの件数だけでした。ただ、件数だけを見ていた時期は、件数が同じでも総露出（その週に送ったリプライの表示回数の合計）が半分以下に落ちていることに気づかず、同じ画面を17週見続けました。いまは毎週、自発投稿を出した日数と平均、リプライの件数と総露出、100インプレッション以上の本数、新規フォローと離脱の4つを前週と並べています。9月28日からの2週は、総露出が減ってもフォロワーが増えていて、リプライだけでは説明がつかなくなっています。

AIで投稿を自動にしたのに、インプレッションやフォロワーが伸びない。あるいは落ちて、AIに書かせる文章を作り直そうとしている。そういう人に向けて書いています。数字はすべて、AIに農家のおじいちゃんを演じさせているXアカウントの記録です。自発投稿はAIが書いて自動で出し、リプライは私が手で送っています。2026年4月4日にフォロワー1人で始めて、10月11日時点で169人になりました。

## 7月、毎日投稿していたのにフォロワーが減った

7月13日から19日の週、フォロワーは115人から127人に増えました。翌週の20日から26日には、127人から124人へ減っています。

その月、自発投稿を休んだのは29日の1日だけです。写真の撮り方も、添える文章の長さも、それまでと同じです。毎日同じように出していて減ったのだから、投稿が読まれなくなったのだろう、書き方を変えるべきだ、と私は考えました。

文章を疑ったわけです。

次の5日間、7月27日から31日も、フォロワーは1人減りました。

## 変わっていたのは、リプライの件数だけだった

7月の4週間を並べると、動いていた数字は1つしかありませんでした。

| 期間 | 送ったリプライ | フォロワーの増減 |
|---|---:|---:|
| 7月6日〜12日 | 60件 | +8 |
| 7月13日〜19日 | 57件 | +12 |
| 7月20日〜26日 | 14件 | -3 |
| 7月27日〜31日（5日間） | 0件 | -1 |

自発投稿は、29日の1日を除いて毎日出しています。写真も文章の長さも変えていません。誰に送ったかも、ほとんど変わっていませんでした。初めての相手へのリプライの割合は、57件の週が77%、14件の週が79%です。増えた週も減った週も、77〜81%の間に収まっていました。

変わったのは、送った数です。57件から14件に落ちた週にフォロワーが減り、0件の5日間にもまた減りました。その週に送ったリプライの表示回数の合計は、57件の週の850から、14件の週には148まで下がっています。この記事では、この合計を「総露出」と呼びます。

私が疑っていた文章は、この4週間ずっと同じ書き方のままでした。

## リプライは、ふだんは届かず、ときどき大きく届く

自発投稿とリプライは、届き方の形が違いました。

1本ずつの表示回数を9月20日までで比べると、中央値は自発投稿196件が61.5回、リプライ1,096件が12回です。ふだんの1本なら、自発投稿のほうが5倍ほど見られています。

形が逆になるのは、上の端です。自発投稿で9月20日までにいちばん表示されたのは、8月12日の186回でした。リプライのほうには、2,000回を超えたものが2本あり、1,000回を超えた3本はどれもリプライでした。10月3日には自発投稿が494回まで届きましたが、リプライの上の2本とはまだ4倍以上の差があります。

言葉が返ってくる割合も違いました。4月3日から8月12日までに、自発投稿は168件出して、リプライが付いたのは18件です。約11%でした。こちらから送った一言は933件あり、返信が返ってきたのは340件です。多く見積もって約36%です。Xの返信数には、こちらが同じスレッドに重ねた返信も混じるので、この割合は上限として読んでください。

自発投稿は、出したあと誰かが来てくれるのを待つ投稿です。リプライは、こちらから相手の投稿へ出向いて一言置いてくるものです。

送っていた一言は、たとえばこういうものです。

- 「すごいのう。」
- 「水につけて根が出たか、おめでとう🙌」
- 「脇芽は葉の付け根（葉腋）から伸びるやつじゃ…」

3つ目が途中で切れているのは、ログに冒頭50字までしか残っていないからです。どれも、おじいちゃんの口調で相手の投稿に短く一言足しているだけで、凝った文章ではありません。ただ、「すごいのう。」だけを送ったものには、返信が0件のまま終わったものも多くありました。

それで私は、リプライを知らない人の前に出る入口、自発投稿をその入口から入ってきた人が読む材料、と考えるようになりました。7月の私は、入口に立つのをやめた週に、材料のほうを作り直そうとしていました。

## 件数を戻しても、総露出が戻っていなかった

ここまでなら、件数を戻せば済む話です。私も長いあいだ、そう考えていました。

5月4日から10日の週、リプライは58件でした。総露出は4,881で、フォロワーは25人増えています。上の表の最初の週、7月6日から12日には60件送っています。総露出は2,066で、増えたフォロワーは8人でした。件数はほとんど同じなのに、結果が揃いません。

いちばんこたえたのは、この差に気づくのが遅れた理由のほうでした。インプレッションの数字は、週次レポートの元データに5月から毎週入っていました。ところが私が読むレポートの画面には、件数しか転記していなかったのです。私はその画面を17週見続けました。総露出の数字は、そのあいだ一度も画面に出てきませんでした。件数しか並んでいない画面からは、件数をどうするか以外の1手は出てきません。

元データから約1,000件のリプライを表示の多い順に並べ直すと、上位5%にあたる50件が、約1,000件の表示回数の合計の55%を作っていました。ある週は、その週の総露出の約6割が1件に集中しています。その大きく届く側のリプライが消えていました。100インプレッション以上のリプライは、5月に32本、6月に19本、7月は1本、8月も1本です。

新規フォローと離脱に分けても、同じ形が出ました。新規フォローは5月の+64から8月の+17まで落ちています。離脱は6月以降ほぼ一定で、毎月-6から-8の間でした。出ていく人の数は変わらず、入ってくる人だけが減っていました。

このとき私は、悪かったのは入口だと結論づけました。

最初の2週は、入ってくる人がほぼいませんでした。新規フォローは0人と1人です。

9月14日から件数を58件に戻しても、その週のフォロワーは1人しか増えませんでした。総露出は増えたのに、100インプレッションを超えたリプライは0本のままです。

2週目の9月21日からは71件を送り、新規8人・離脱0人で142人になりました。この週に100インプレッションを超えた5本は、どれもリプライではなく自発投稿で、9月に入って初めてでした。自発投稿もこの週から7日とも出ています。リプライの件数を戻したことと、自発投稿が毎日に戻ったことのどちらが効いたのかは、この記録では分けられません。

3週目と4週目は、リプライが入口だという見方と合わなくなりました。総露出は1,188から937、876と2週続けて減り、リプライ1件あたりの表示回数の中央値も14、12、11と下がっています。それでもフォロワーは13人、14人と増えました。週に14人は、5月4日〜10日の週の25人以来の増え方です。総露出が半分以下でも、7月6日〜12日の週（総露出2,066で8人増）より大きく増えています。

同じ時期に上がり続けていたのは、自発投稿の平均インプレッションです。9月14日〜20日の71.2から、114.6、146.9、167.1と上がり、毎日投稿も3週続いています。ただ、自発投稿が届いたからフォロワーが増えたのか、フォロワーが増えたから自発投稿が届いたのかは区別できません。誰がどの投稿から来たのかは記録していないからです。週ごとの詳しい数字は [毎週の実測](/weekly) にあります。

リプライが入口だという見方は、9月までの記録から出したものです。直近の記録は、その見方だけでは説明できません。

## いま毎週見ている4つ

数字が減った週は、文章を直す前に次の4つを前週と並べています。

1. **自発投稿を出した日数と、その平均インプレッション**。写真を送れなかった日があれば、自動の側はそこで止まっている。9月下旬から並べ始めた
2. **リプライの件数と総露出**。件数だけを見て17週気づかなかったので、必ず2つを並べる。上位5%のリプライが表示回数の合計の半分以上を作るので、最大の1件を除いても落ちているかも見る
3. **100インプレッション以上の投稿の本数**。合計は1件で動くが、本数は動きにくい。100という線は、このアカウントで便宜上置いている基準
4. **新規フォローと離脱**。純増だけだと、入口が悪いのか、残ってもらえていないのかが区別できない

件数が前週と同じなのに総露出が落ちていたら、そこで初めて何かを変えます。変えるのは1つだけで、私の場合はリプライ先の選び方でした。投稿の中身にも頻度にも、その週はまだ手をつけません。2つ同時に変えると、翌週の数字がどちらの結果なのか読めなくなるからです。

### 4つとは別に、投稿1本ずつを見るとき

4つは週全体の数字です。投稿1本ずつを比べるときは、いいねをインプレッションで割って並べ直します。5月に送ったリプライのうち、Aは2,153インプレッションでいいね5、0.23%でした。Bは313インプレッションでいいね10、3.2%です。表示回数で選べばA、割り算で選べばBが残り、来週に試す1本が変わります。書き込む枠と記入例は[5分で終わる週1回の振り返りシート](/sns-weekly-review)にまとめました。

## この記録で分からないこと

ここにあるのは1つのアカウントの記録です。リプライがフォロワー増を引き起こしたとまでは言えませんし、9月21日からの3週にどの投稿が人を連れてきたのかも分かりません。他のアカウントで同じことが起きるかも未確認です。9月の数字は日本時間の月曜〜日曜の合計で、新規フォローと離脱は毎日のフォロワー数の増減から出したものです。同じ日に増えて減った分は打ち消し合うので、実際より小さく出ます。

## 作り直す前に、人の手でやっている側を数える

投稿の作り直しは、一人でできて、進んでいる感覚も得やすい作業です。AIへの指示を書き換えるだけなら、なおさら手軽です。相手の投稿へ一言送りに行くほうは手間がかかり、返事が来ないこともあるので、つい後回しにしたくなります。7月の私は、その後回しにしたほうで数字を落とし、作り直すほうに手を伸ばしかけました。

投稿を自動にすると、自発投稿は同じ調子で出続けます。このアカウントで数字が動いた週に変わっていたのは、7月はリプライの件数でした。9月は、リプライの件数と、写真を送って自発投稿を出せた日数です。どちらも自動の側ではなく、人の手でやっている側でした。

インプレッションやフォロワーが落ちた週は、文章に手を入れる前に、前週と2つを並べてみてください。今週は何日写真を送れたか。リプライを何件送り、それが何回表示されたか。作り直すかどうかは、そのあとで決めても遅くありませんでした。
