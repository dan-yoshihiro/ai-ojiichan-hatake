# Xのインプレッションが落ちたら、文章を直す前に確認したい4項目

*公開: 2026-08-28 / 最終更新: 2026-09-12 / 記録者: [@ojiichan_hatake](https://x.com/ojiichan_hatake) / 根拠: 1アカウントの週次記録と運用履歴*

> **TL;DR:** インプレッションが落ちても、先に文章を書き直す必要はありません。Xのアナリティクスから「実施量・届いた量・当たり・新規と離脱」を順に見れば、次週に確認することを1つに絞れます。これは1アカウントの実測記録です。

![実施量の低下、突出した投稿、投稿種別を順に確認してインプレッション低下を調べる図。](/static/hero-impressions-drop.webp)

この記事は、インプレッションが落ちたときに投稿内容のせいと決めそうになっている個人運用者向けです。最初は、リプライ数と総露出を前週と並べるだけで構いません。割り算の前に実施量を見る順番は、[5分でできるX投稿の週次振り返り](/sns-weekly-review) にあります。

## 最新週では、純増より前に入口を見た

W36（8月31日〜9月6日）は、リプライ18件、リプライ経由の総露出129、100インプレッション以上の当たり0本でした。フォロワーは134人から133人へ動き、新規フォロー0人・離脱1人という内訳でした。

| 見る順番 | W36の数字 | ここで決めないこと |
|---|---:|---|
| 実施量 | リプライ18件 | 件数だけが原因だったこと |
| 届いた量 | 総露出129 | 文章だけが原因だったこと |
| 突出投稿 | 当たり0本 | 当たりを再現できること |
| 入口・出口 | 新規0人 / 離脱1人 | 投稿が増減を引き起こしたこと |

「-1」という純増だけを見ても、入口が止まったことと、離脱が1人あったことは区別できません。次週に試すことを選ぶ前に、どの段で数字が変わったかを残します。

## 最初は、投稿の書き方が悪かったのだと思った

この記録は、AIに固定ペルソナを与えて運用したXアカウントのものです。

リプライを57件送った週は、フォロワーが115人から127人へ増えました。一方、翌週はリプライが14件しかできず、フォロワーは127人から124人へ減りました。リプライ経由のインプレッションも850から148へ下がっています。

数字だけを見ると、「投稿が読まれなくなった」「書き方を変えるべきだ」と考えたくなります。しかし、この週は投稿内容の比較より先に、運用そのものが前週と同じ条件ではありませんでした。

| 指標 | リプライ57件の週 | リプライ14件の週 |
|---|---:|---:|
| リプライ送信数 | 57件 | 14件 |
| 新規の相手へのリプライ割合 | 77% | 79% |
| リプライ経由インプレッション | 850 | 148 |
| フォロワー週増 | +12 | -3 |

この表は、リプライ数がフォロワー増減の原因だと証明するものではありません。ただし、投稿の良し悪しを決める前に、「活動量が同じだったか」を確認すべき状況だったことは分かります。インプレッションは届いた量、リプライ数は実施量です。2つを混ぜると、内容の問題と条件の変化が区別できません。

> **一文でいうと:** インプレッションが落ちた週に、投稿内容のせいと決めるのは早すぎるかもしれません。

## 分けて見た4つ

### 1. 投稿とリプライを分け、実施量が変わっていないかを見る

自発投稿とリプライは役割が異なります。この記録では、リプライを週60件前後行った週は新規接触を作れていました。一方、ある週はリプライ数が57件から14件へ低下し、フォロワー週増も+12から-3へ動きました。

これは「リプライだけが原因」と示すものではありません。ただ、投稿の良し悪しを考える前に、そもそも前週と同じ活動量だったかを確認する理由になります。

| 確認する数 | 見る理由 |
|---|---|
| 自発投稿数・投稿日数 | 投稿機会そのものが減っていないか |
| リプライ送信数 | 新しい読者と接触する量が変わっていないか |
| 新規の相手へのリプライ割合 | 同じ相手だけに偏っていないか |

### 2. 1件の突出投稿を除いても落ちているかを見る

週の合計インプレッションは、1件だけ大きく伸びた投稿で大きく変わります。実測では、ある週のリプライ経由インプレッションの約6割が1件に集中していました。翌週にそのような投稿がなければ、合計は下がります。

合計だけで「今週は弱かった」と決めず、次を並べます。

1. 最大インプレッションの投稿
2. 中央値または普段の投稿の範囲
3. 最大投稿を除いた合計

突出投稿がなくなっただけなら、投稿全体の水準まで下がったとは言えません。逆に、最大値を除いても複数の投稿が下がっているなら、次週に検証する材料になります。

### 3. 自発投稿とリプライを同じ平均にしない

リプライは相手の投稿に表示されるため、自発投稿とは届き方が異なります。両方を混ぜた平均では、「自分の記事が読まれなくなった」のか、「リプライ活動が減った」のかが分かりません。

まず以下の2表に分けます。

| 種別 | 確認する数 |
|---|---|
| 自発投稿 | 件数、平均・中央値のインプレッション、いいね率、保存・共有 |
| リプライ | 送信数、新規相手の割合、平均・中央値のインプレッション、返信の有無 |

### 4. 純増を、入口と出口に分ける

フォロワーの純増は、新規フォローと離脱の差です。W36の「-1」は、新規0人・離脱1人でした。どちらか一方しか見ないと、「届かなかった」のか「定着しなかった」のかを同じ数として扱うことになります。

分けても、投稿との因果関係は分かりません。それでも、次に確認する場所を「文章全体」から、入口・露出・当たり・実施量のどれか1つへ絞れます。

## この週に、すぐ投稿内容を変えなかった理由

実施量が落ちている週に、文体・投稿時間・テーマまで同時に変えると、翌週に何を見直すべきか分からなくなります。この記録ではまず、リプライ送信数を戻せるかを次の確認事項にしました。

ここで大切なのは、同じ結果を再現することではありません。自分のアカウントで数字が落ちたとき、「投稿内容の問題」と決める前に、前週から変わった条件を1つずつ確認できる状態にすることです。

## この記録から分かること・分からないこと

- 分かること: 実施量、投稿種別、突出投稿を分けると、数字が下がった週の観測対象を絞れること
- 分からないこと: 特定の施策がインプレッションやフォロワー増加を引き起こしたこと

この週のシートに書くなら、6行目は「投稿内容を変える」ではなく「リプライ送信数を戻せるか確認する」です。5行目のまだ分からないことは、「減ったのは文章のせいなのか、件数が減ったせいなのか」です。
