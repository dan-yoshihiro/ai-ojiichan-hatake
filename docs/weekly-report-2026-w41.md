# Xの週次振り返り実例：リプライの露出が2週続けて減っても、フォロワーが14人増えた週（2026年10月5日〜11日）

*公開: 2026-10-11 / 最終更新: 2026-10-11 / 記録者: [@ojiichan_hatake](https://x.com/ojiichan_hatake) / 集計基準: 月曜〜日曜（日本時間）の投稿 / 比較対象: 9月28日〜10月4日*

> **TL;DR:** AIが自発投稿を書き、リプライは人が送っている家庭菜園のXアカウントの1週間です。リプライは66件から69件に増えましたが、リプライ経由の総露出は937から876へ約7%減り、100インプレッションを超えたリプライは0本でした。それでもフォロワーは155人から169人へ14人増え、5月4日〜10日の週（25人）以来の増え方です。自発投稿は7日とも出ていて、平均インプレッションは3週続けて増えました。前週に決めた「リプライの2割を以前の相手に送る」は実行できていません。来週はリプライ60件のうち5件を、以前に100インプレッション以上届いたことのある相手に送ります。

AIに投稿を任せたあと、毎週どこを見ればいいかを知りたい人向けに、[週1回の振り返りシート](/sns-weekly-review) の枠へそのまま実測を書き込んでいます。

## 0. 今週の目的

前週に決めた1手は「リプライのうち2割を、以前に返したことのある相手に送る」でした。自発投稿の型・頻度・時間帯と、リプライの件数（週60件）は変えない予定でした。

## 1. 週全体の条件：リプライは増え、露出は減り、フォロワーは増えた

リプライの件数は3件増え、総露出は61減りました。フォロワーの増え方は前週の13人を上回る14人です。

| 指標 | 10月5日〜11日 | 前週（9月28日〜10月4日） | 前週差 |
|---|---:|---:|---:|
| 自発投稿数 | 8件（7日） | 9件（7日） | -1件 |
| リプライ数 | 69件 | 66件 | +3件 |
| リプライ経由の総露出 | 876 | 937 | -61（-7%） |
| リプライ1件あたりの平均インプレッション | 12.70 | 14.20 | -1.50（-11%） |
| 100インプレッション以上の自発投稿 | 8本 | 6本 | +2本 |
| 100インプレッション以上のリプライ | 0本 | 1本 | -1本 |
| フォロワー数 | 169人 | 155人 | +14人 |
| 新規フォロー / 離脱 | +18人 / -4人 | +13人 / 0人 | — |

リプライ経由の総露出は、その週に送ったリプライの表示回数の合計です。

## 2. 気になった投稿：表示回数の1位と、いいね率の1位はまた別だった

数字が揃った自発投稿7本（10月11日朝の1本はまだ揃っていない）のうち、表示回数が最も多かった投稿と、いいね率が最も高かった投稿を並べます。

| 投稿 | テーマ・型 | 種類 | インプレッション | いいね | いいね率 |
|---|---|---|---:|---:|---:|
| A | 本葉が大きくなった小松菜を見て、間引きを済ませたかを尋ねる | 自発投稿・観察 | 262 | 23 | 8.78% |
| B | 本葉を広げた小松菜を見て、次の間引きに触れる | 自発投稿・観察 | 145 | 18 | 12.41% |

投稿Aは262インプレッションで、この週で最多でした。前週は494の1本が飛び抜けていましたが、今週はそうした1本はなく、7本すべてが132〜262の間に入っています。3週続けて、表示回数の1位といいね率の1位は別の投稿です。

リプライでは、いちばん届いた1件でも40インプレッションでした。100を超えたリプライはありません。

## 3. その数字

- 自発投稿は9件から8件。7日とも投稿があり、毎日投稿は3週続いた
- 数字が揃った自発投稿7件の平均インプレッションは167.1、平均いいねは16.43（前週は9件で146.9と11.67）
- 投稿の冒頭50字に「間引き」が入っていたのは8本中6本。前週の芽の観察から、間引きの話題に移った
- リプライは66件から69件。1件あたりの平均いいねは0.58から0.64
- リプライのインプレッションの中央値は12から11。10インプレッションに届かなかったリプライは23件から27件に増えた
- この週にリプライした67人（同じ相手に重ねて送った分があるので、69件より少ない）は、全員が以前に返したことのない相手だった。初めての相手だけになったのは3週続けて
- フォロワーは155人から169人へ、純増14人（新規18人・離脱4人）

## 4. 分かったこと：リプライの届いた量では、2週続けて増え方を説明できない

リプライ経由の総露出は2週続けて減り（1,188 → 937 → 876）、そのあいだもフォロワーの増え方は大きくなりました（+8 → +13 → +14）。

- 7月6日〜12日の週はリプライ60件・総露出2,066で8人増だった。今週はその半分以下の露出で14人増えた
- リプライ1件が届く人数は減り続けている。中央値は9月21日〜27日の14から、12、11と下がった
- 自発投稿の平均インプレッションは、9月14日〜20日の71.2から、114.6、146.9、167.1と3週続けて増えた
- 前週に決めた1手は実行できなかった。以前の相手に送ったリプライは0件で、目標の2割に届いていない
- 離脱の4人は、10月9日の1日に出た。この日は167人から163人に減り、翌日は168人に戻っている

## 5. まだ分からないこと

- 新規18人が、自発投稿・リプライ・3週続けた毎日投稿のどれで来たのか。誰がいつフォローしたかは記録していない
- 自発投稿の平均インプレッションが増えたのは、フォロワーが増えた結果なのか、増えた原因なのか
- 10月9日の4人減が、本当にフォローを外した4人なのか、X側の数え直しなのか。翌日に戻っているが、どちらかは決められない
- 以前に大きく届いた相手に返すと、リプライの届く量が戻るのか。前週に試す予定だったが、試せていない

## 6. 来週、1つだけ試すこと

**[変える] リプライ60件のうち5件を、以前に100インプレッション以上届いたことのある相手に送る。**

前週は2割（12件ほど）と決めて、1件も送れませんでした。新しい相手を探す流れの中で、以前の相手に戻る手順が入っていなかったためです。決めた1手も、人の手順に組み込まなければ実行されない。[AIに投稿を任せて人に残った仕事](/ai-x-operation)と同じことが、週の1手でも起きました。

今週は件数を12件ほどから5件に下げます。相手の条件も、前週の「以前に返したことのある相手」から「以前に100インプレッション以上届いたことのある相手」に変えています。これまでに100インプレッション以上届いたリプライ61本のうち、58本は4〜6月に送ったものです（前週の記録で「5〜7月」と書いていたのを、月別に数え直しました）。

残りの55件は今までどおり初めての相手に送ります。自発投稿の型・頻度・時間帯と、リプライの合計件数は変えません。

## データ上の注意

- 投稿は、日本時間の月曜0時〜日曜24時に出したものを数えた
- 投稿ごとの数字は、投稿の20〜44時間後に毎日集めている値。10月11日朝の自発投稿1件（集計時点で206インプレッション）はまだ数字が揃っていないので、平均と投稿の比較から外した。100インプレッション以上の本数には含めている
- 10月11日に送ったリプライ18件も、まだ数字が揃っていない。前週は日曜分が揃ったあと、総露出が910から937に増えた。今週の876も後から増える可能性がある
- フォロワー数は毎日20時半の記録。新規フォローと離脱は、増えた日の増分と減った日の減分をそれぞれ足したもの。同じ日のうちに増えて減った分は打ち消し合うので、実際の新規と離脱より小さく出る
- 返信先の表示回数は9月19日から記録している。ここまで213件を突き合わせると、返信先が1,000回以上表示されていた2件だけリプライの中央値が102で、それ以外の表示回数の帯はどれも中央値10〜13だった。2件しかないので判断には使っていない。突き合わせは相手と日付から推定したもの
- 数字から、投稿とフォロワー増加の因果関係は断定しない
- 前週（9月28日〜10月4日）の総露出は、公開時に910と書いていた。日曜に送ったリプライの数字が後から揃い、937になっている（[前週の記録](/weekly/2026-w40) も直した）
- 訂正（2026-10-11）: 公開時は「冒頭に『間引き』が入っていたのは8本中5本」と書いていた。冒頭50字で数え直すと6本。TL;DRの「平均インプレッションは2週続けて増えた」も、本文どおり3週に直した
