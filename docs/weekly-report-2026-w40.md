投稿Aは494インプレッションで、観測を始めてからの自発投稿でいちばん多い数字でした。それまでの最多は186です。ただ、いいね率はこの週の集計済み8本のうち下から2番目です。投稿Bは表示回数が約5分の1で、いいね率は約4.4倍でした。前週と同じく、表示回数1位といいね率1位は別の投稿です。

リプライでは、約7,400回表示されていた投稿へ返した1件が142インプレッションに届きました。この週のリプライで100を超えたのはこの1件だけです。

## 4. 分かったこと

- 前週の記録で決めた1手は「この型の自発投稿を1本だけ試す」だったが、この週の目的では「この型を続ける」に広げていて、実際に8本中7本がこの型になった。1本だけ変えて比べる形にはなっていない。7本のうち4本のいいね率は11〜14%で、前週の投稿B（11.97%）と同じ水準を保ったが、型の違う投稿がほぼ無いので、型が効いたかどうかは決められない
- リプライの件数も総露出も前週より減ったのに、フォロワーの増え方は前週の8人より大きい13人だった
- 7月6日〜12日の週はリプライ60件・総露出2,066で8人増、8月10日〜16日の週は63件・1,032で8人増だった。それより少ない露出で、増え方は大きい
- 自発投稿は件数がほぼ同じで、平均インプレッションが増えた。100インプレッションを超えた1本は494に届いた
- 離脱は2週続けて0人だった

## データ上の注意

- 投稿は、日本時間の月曜0時〜日曜24時に出したものを数えた
- 投稿ごとの数字は、投稿の20〜44時間後に毎日集めている値。10月4日20時台の自発投稿1件は公開時にまだ数字が揃っていなかったので、投稿の比較から外した。平均は、揃ったあとの9件で直している
- フォロワー数は毎日20時半の記録。新規フォローと離脱は、増えた日の増分と減った日の減分をそれぞれ足したもの。同じ日のうちに増えて減った分は打ち消し合うので、実際の新規と離脱より小さく出る
- 返信先の表示回数は9月19日から記録している。ここまで129件を突き合わせると、返信先が1,000回以上表示されていた2件だけリプライの中央値が102で、それ以外の表示回数の帯はどれも中央値10〜13だった。2件しかないので判断には使っていない。突き合わせは相手と日付から推定したもの
- 数字から、投稿とフォロワー増加の因果関係は断定しない
