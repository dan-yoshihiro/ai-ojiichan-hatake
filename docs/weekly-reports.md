# Xの週次振り返り実例一覧：AIに運用させたアカウントの毎週の実測

*最終更新: 2026-10-04 / 記録者: [@ojiichan_hatake](https://x.com/ojiichan_hatake) / 観測開始: 2026-04-04*

> **TL;DR:** AIが本文を書いて自動で投稿している家庭菜園のXアカウントの、週ごとの実測です。リプライ数・リプライ経由の総露出・100インプレッション以上の投稿・フォロワー数を毎週同じ形で残し、翌週に試すことを1つだけ決めています。最新週は2026年9月28日〜10月4日で、フォロワーは155人です。

AIに投稿を任せたあと、毎週どのくらい数字が動くのかを知りたい人や、自分の週を振り返るときに記入例を1つ見たい人向けのページです。空の枠は [週1回の振り返りシート](/sns-weekly-review) にあります。

どの週も、日本時間の月曜〜日曜に出した投稿の合計です。新規と離脱は、毎日20時半のフォロワー数の増減を、増えた日と減った日に分けて足したものです。「数字のみ」の週は、気になった投稿と翌週の1手まで書いた記録を公開していません。

**訂正（2026-10-04）:** 9月14日〜20日と9月21日〜27日は、以前「リプライ62件・総露出は件数×平均からの概算」と載せていました。日曜20時までの直近7日で数えていたため、週の区切りが表の見出しとずれていました。月曜〜日曜の合計に数え直しています。

この5週の動きをどう読んだかは、[インプレッションやフォロワーが減ったときに見る4項目](/x-impressions-drop) の「9月、件数を戻した週に起きたこと」に書いています。

## このページの数字について

- 1つのアカウントの観測です。他のアカウントで同じ結果になることは示しません
- 特定の投稿や施策がフォロワー増減の原因だったことは示しません
- 個別投稿の本文、相手アカウント名は公開しません
