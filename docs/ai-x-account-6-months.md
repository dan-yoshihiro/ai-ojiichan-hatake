# AIでX運用を6ヶ月：自動投稿は書くところまで任せられたが、止まったのはいつも私の側だった

*公開: 2026-10-02 / 最終更新: 2026-10-02 / 記録者: [@ojiichan_hatake](https://x.com/ojiichan_hatake) / 観測期間: 2026-04-04〜2026-09-27*

> **TL;DR:** AIにXの自動投稿を任せて、うまくいったのは言葉の決まりを守らせることでした。「元気な」を含む定型の投稿は、62%から6%に減っています。止まったのは人の側です。171日のうち投稿があったのは151日で、止まった週の自分のメモには「時間が取れなかった」とあります。いちばん多く表示された1本は、私が手で送ったリプライでした。数字は自動で集まっていたのに、どれを画面に出すかは決めていませんでした。AIと自動処理に任せられたのは、書いて出すことと、数字を集めることまでです。

AIに書かせれば、毎日の投稿は止まらない。始める前の私は、そう考えていました。

AIにSNSの投稿を任せたい人、任せようか迷っている個人運用者に向けた記録です。アカウントは「おじいちゃんの畑」で、AIに農家のおじいちゃんを演じさせています。畑は2階の南向きのベランダ、育てているのはミニトマトと小松菜です。運用しているのはエンジニアの私1人です。

## 「AIだから毎日止まらない」と書いた日

2026年4月4日、フォロワー1人で始めました。最初の目標は「1ヶ月で100人」です。15日経った4月19日、フォロワーは10人でした。目標は、5月末までに50人へ下げました。

同じ4月19日に、アカウントの設計書を1本作っています。北極星として置いたのは、この1文です。

「AIなのに毎日失敗して、毎日学んで、毎日ベランダのミニトマト1鉢と向き合い続けるおじいちゃん農家」

1文のなかに「毎日」が3回出てきます。ほかのアカウントとの違いを並べたところには、軸の1つとして「AIだから毎日止まらない」とも書きました。

4月3日から9月20日までの171日のうち、自発投稿があったのは151日でした。

投稿が止まった週、私は自分用のメモにこう残しています。「時間が取れなかった。意欲でも手順でもなく時間が制約」。読み返すと、設計書の1行とメモの1行がちょうど向かい合っています。止まったのはAIが書く手前で、写真を撮ってLINEに送る私のところでした。

この記事は、AIに投稿を任せた約6ヶ月で、何がAIの側に移り、何が人の側に残ったかの記録です。残ったものは3つありました。続ける時間と、相手の投稿へ出向くことと、どの数字を見るかの判断です。フォロワーは9月27日に142人になっています。

## 写真を送ったあとは、人の手を通らない

止まった場所がどこにあるのかは、流れのなかで見たほうが分かりやすいので、先に仕組みを書いておきます。

ベランダで撮った写真をLINEに送ると、Make がそれを受け取ります。次に、Dify 上で動かしている Gemini 2.5 Flash が、作物ごとの栽培メモを参照して、おじいちゃんの口調で本文を書きます。栽培メモはミニトマト用と小松菜用の2つです。書けた本文はもう一度 Make を通って、本文と作物の区分に分けられます。最後に Google Apps Script がハッシュタグを付け、X API から投稿します。写真を送ったあと、ここまで人の手は入りません。

リプライは別の流れです。菜園アカウントの投稿を見て、送る相手を私が選びます。相手の投稿をAIに貼ると、口調を揃えた草案が2案出てきます。どちらかを選んで送るのも私です。

数字は毎日自動で記録していて、投稿ごとの数字とフォロワー数が溜まっていき、日曜にはそれをまとめた週次レポートが自動で出ます。

| 作業 | 担当 |
|---|---|
| 写真を撮ってLINEに送る | 私 |
| 自発投稿の本文を書き、Xに出す | AIと自動処理 |
| リプライの相手を選び、送る | 私 |
| リプライの草案を2案出す | AI |
| 数字の記録と週次レポート | 自動 |
| レポートを読んで来週の1手を決める | 私 |

全部を自動にできたわけではありません。人の手を通らずに回っているのは、自発投稿と数字の記録だけです。表で「私」が担当している3行が、このあと止まった3つにそのまま対応しています。

## AIに任せて効いたこと：言葉の決まりを表にする

止まった話の前に、うまくいった側を書いておきます。

4月19日の設計書には、使う言葉と避ける言葉の表を入れました。避ける言葉には1つずつ、理由と代わりの書き方を添えています。たとえば「元気な〜じゃのう」を連発すると単調になるので、冒頭は4種類の型から選ぶ、という具合です。

表を作る前の自発投稿は32件で、そのうち20件に「元気な」が入っていました。62%です。作ったあとの164件では、「元気な」を含む投稿は10件、6%でした。

表に書いた決まりは、あとから本文を検索すれば、守られたかどうかを数えられます。AIに任せてはっきり手応えがあったのは、この種類の仕事でした。

いいねも同じ2期間で、平均0.69から6.80に増えています。ただ、そのあいだフォロワーも増え続けていたので、表のおかげとは言えません。

## 止まったこと1：撮って送る時間がなかった

表の「私」の1行目、写真を撮ってLINEに送るところから止まりました。

月ごとに投稿のあった日を数えると、4月が27日、5月が30日、6月と7月も30日ずつです。8月は20日に落ち、9月は20日時点で14日でした。いちばん長く空いたのは3日で、8月7日から9日と、9月14日から16日の2回です。

5月から7月の3ヶ月は、ほぼ毎日出ていました。それがあるぶん、8月の20日と9月の14日が目立ちます。

自発投稿の流れで私の手が入るのは、最初の1段だけです。写真を撮って、LINEに送る。そこから先は、すべて自動にしてありました。手順を減らせるだけ減らしたので、人の手が要る場所は、私が写真を撮って送るかどうかの1か所しか残っていませんでした。

メモに書いた「意欲でも手順でもなく」は、その週の自分なりの切り分けでした。意欲が落ちたのでも、手順が面倒だったのでもない。残っていたのは時間でした。

AIは写真が届けば書きます。撮って送る人がいなければ、何も始まりません。

設計書の「AIだから毎日止まらない」は、流れのうちAIの段だけを見て書いた1行でした。北極星の1文に3回書いた「毎日」も、実際にかかっていたのはAIの毎日ではなく、写真を送る私の毎日です。

## 止まったこと2：知らない人に届いていたのは、手で送るリプライだった

表の「私」の2行目は、リプライの相手を選んで送るところです。

自発投稿でいちばん表示された1本は176回でした。当時のフォロワーは約120人です。自発投稿は、いちばん見られた1本でも、フォロワー数を少し超えたあたりで止まっています。リプライのほうには、2,153回表示された1本がありました。リプライは相手の投稿の下に並ぶので、相手の投稿を見ている人の前にも出ます。このアカウントでいちばん多く表示された1本は、自発投稿ではなく、私が手で送ったリプライでした。

言葉が返ってくる割合も違いました。4月4日から8月12日までの自発投稿167件のうちリプライが付いたのは17件で約10%、こちらから送った一言933件では340件に返信が返ってきて、多く見積もって約36%です。

7月20日から26日の週も、自発投稿は毎日出ていました。その週はリプライを14件しか送っておらず、フォロワーは3人減っています。

リプライは、相手を選ぶところも送るところも私がやっています。AIが出すのは草案の2案までです。誰の投稿へ出向くかと、実際に送ることは、人の手に残っていました。週ごとの件数と届いた量の動きは、[インプレッションやフォロワーが減ったとき、投稿を直す前に見る4項目](/x-impressions-drop)に詳しく書いています。

## 止まったこと3：数字は集まっていたのに、画面に出していなかった

表の「私」の3行目は、週次レポートを読んで来週の1手を決めるところです。

数字は毎日、自動で溜まっていました。けれど週次レポートの画面に出ていたのは、リプライの件数とフォロワーの純増だけです。インプレッションの数字は5月から毎週元データに入っていたのに、画面には転記していませんでした。

その画面を、私は17回開いています。

そして毎回、リプライの件数を戻すと決めました。

5月4日から10日の週はリプライ58件、7月6日から12日の週は60件で、件数はほとんど変わりません。リプライ経由のインプレッションは4,881と2,066、フォロワーは+25と+8でした。件数と純増しか出ない画面では、この2週はどちらも「60件前後送った週」に見えます。

集める作業は自動にできても、どれを人の目の前に出すかは、私が決め直さないかぎり最初に作った形のままでした。いまは週次レポートに、リプライ経由の総露出、100インプレッション以上の投稿の本数、新規フォロー、離脱を足しています。

## 書かせない決まりと、かかっている費用

ここは短く書きます。AIへの指示には、次の決まりを入れています。

- 農薬の濃度・量・希釈倍率は書かない
- 病気を言い切らず、「〜かもしれん」と書く
- 人間の思い出を作らない。祖父や父の話、幼いころの話は書かない
- 政治・宗教・差別的な表現は書かない

このうち機械でも確かめているのは、農薬の1つだけです。投稿の直前に、本文に「ml」「cc」「倍に薄めて」「希釈」が入っていないかを調べます。1つでも入っていればXには出さず、LINEへの返答だけを返します。残りの3つは、AIへの指示だけで守らせています。

費用は、生成AIが無料枠の範囲です。X API は従量課金で、上限を5ドルに決めて自動チャージを切っています。

## この記録で分からないこと

1つのアカウントを1人で回した約6ヶ月の記録です。ほかのアカウントで同じことが起きるかは分かりません。投稿日数やリプライの件数がフォロワーの増減を引き起こしたとまでは言えません。

## AIで運用を始める前に、私なら決めておく3つ

AIと自動処理に任せられたのは、書いて出すことと、数字を集めることまででした。書く手前の時間と、書いたものをどこへ持っていくか、そして結果のどこを見るか。この3つは6ヶ月ずっと私の側にありました。

1つ目は、写真を撮って送る時間を、自分の1日のどこに置くかです。AIの稼働で「毎日」を約束しても、材料を渡す人が1日空ければ、その日は投稿がありません。

2つ目は、相手の投稿へ出向く時間です。このアカウントでいちばん多く表示された1本はリプライで、相手を選んで送る作業は私の時間でしか回りませんでした。自発投稿の自動化が済んだあとに、ここの時間を別に取っておく必要があります。

3つ目は、週報の画面に何を出すかです。集めるのは自動でも、出す欄を決めるのは人です。件数と純増だけの画面を作れば、私のように17回同じ判断をすることになります。

4月19日の私に1行だけ足させてもらえるなら、「AIだから毎日止まらない」のすぐ下に、「写真を送る私は止まる」と書かせます。自動化の設計図には、AIの段と一緒に、自分の段も書いておくべきでした。
