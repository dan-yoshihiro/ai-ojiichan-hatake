# AIでXを運用して約6ヶ月：写真を送るだけの自動投稿で、フォロワーは1人から142人になった【仕組みと失敗の実測】

*公開: 2026-10-02 / 最終更新: 2026-10-02 / 記録者: [@ojiichan_hatake](https://x.com/ojiichan_hatake) / 観測期間: 2026-04-04〜2026-09-27*

> **TL;DR:** ベランダの野菜の写真をLINEに送ると、AIが農家のおじいちゃんの口調で本文を書き、そのままXへ投稿する仕組みを2026年4月4日から動かしています。フォロワーは1人から始まり、9月27日に142人になりました。AIに任せて効いたのは、言葉の決まりを守らせることでした。定型の書き出しは62%から6%に減っています。任せきれなかったのは3つです。投稿を続ける運用者の時間、相手の投稿へ出向くリプライ、そして集めた数字のどれを見るかの判断でした。

AIにSNSの投稿を任せたい、任せようか迷っている個人運用者向けの記録です。自動化した部分と、手で残した部分を分けて書きます。

アカウントは「おじいちゃんの畑」です。畑は2階の南向きのベランダで、ミニトマトと小松菜を育てています。運用者はエンジニアの私1人です。

## 何をAIに任せ、何を手で残したか

先に全体を表にします。

| 作業 | 担当 | やり方 |
|---|---|---|
| 写真を撮る | 私 | 毎朝ベランダで撮り、LINEに送る |
| 自発投稿の本文を書く | AI | 写真と栽培の知識をもとに、おじいちゃんの口調で書く |
| 自発投稿を出す | 自動 | ハッシュタグを付けて、そのままXへ投稿する |
| リプライ先を選ぶ | 私 | 菜園アカウントの投稿を見て、送る相手を決める |
| リプライの文面 | AI（草案）と私 | 相手の投稿を貼ると、AIが口調を揃えた草案を出す。選んで送るのは私 |
| 数字を集める | 自動 | 毎日、投稿ごとの数字とフォロワー数を記録する |
| 週の振り返り | 自動と私 | 日曜に週次レポートが出る。読んで来週の1手を決めるのは私 |

自発投稿は、写真を送ったあと人の手を通りません。リプライは、相手を選ぶところと送るところに人が入っています。

## 自発投稿が出るまでの仕組み

流れは5段です。

1. LINEに写真を送る
2. ワークフロー自動化ツール（Make）が受け取る
3. 生成AI（Dify 上の Gemini 2.5 Flash）が、作物ごとの栽培メモを参照して本文を書く
4. もう一度 Make を通して、本文と作物の区分を分ける
5. Google Apps Script がハッシュタグを付けて、X API から投稿する

栽培メモは、ミニトマト用と小松菜用に分けてAIに渡しています。

費用は小さく抑えています。生成AIは無料枠の範囲で動かし、X API は従量課金に5ドルの上限を決めて、自動チャージを切っています。

## AIに書かせる前に決めた、書かせないこと

農業の話は、読む人の作物や健康に関わります。AIへの指示には、次の決まりを入れています。

- 農薬の濃度・量・希釈倍率は書かない
- 病気を言い切らない。「〜かもしれん」と書く
- 人間の思い出を作らない。祖父や父の話、幼いころの話は書かない
- 政治・宗教・差別的な表現は書かない

いちばん危ない1つ目は、指示だけに頼っていません。投稿の直前に、本文に「ml」「cc」「倍に薄めて」「希釈」が入っていないかを機械的に確かめ、1つでも入っていればXには出さない段を挟んでいます。AIに「気をつけて」と頼むだけでは、長く回すうちにいつか漏れると考えたからです。

## 約6ヶ月のフォロワー推移

| 日付 | フォロワー数 |
|---|---:|
| 4月4日（開始） | 1人 |
| 5月11日 | 51人 |
| 6月19日 | 100人 |
| 8月12日 | 129人 |
| 9月27日 | 142人 |

最初は「1ヶ月で100人」を目標にしていました。15日経っても10人だったので、目標を5月末までに50人へ下げています。100人に届いたのは開始から約2.5ヶ月後でした。

## AIに任せて効いたこと：言葉の決まりを守らせる

4月19日に、アカウントの設計書を1本作りました。使う言葉と避ける言葉の表を入れ、避ける言葉ごとに理由と代わりの書き方を1つずつ添えています。たとえば「元気な〜じゃのう」の書き出しを連発しない、冒頭は4種類の型から選ぶ、という決まりです。

設計書を作る前の自発投稿は32件で、そのうち20件が「元気な」で始まっていました。62%です。作ったあとの自発投稿は164件で、「元気な」を含むものは10件、6%でした。

人が毎日書いていたら、この決まりはどこかで崩れたと思います。AIは表に書いたとおりに守り続けました。

同じ2つの期間で、平均いいねは0.69から6.80に増えています。ただ、同じ時期にフォロワーも1人から増え続けていたので、表の効果とは言えません。

## 任せても止まったこと1：毎日の投稿は、私の時間で止まった

設計書には「AIだから毎日止まらない」と書きました。

実際には、171日のうち自発投稿があったのは148日です。5月から7月は毎月30日投稿しましたが、8月は21日、9月は20日時点で11日に落ちました。

投稿が止まった週、私は「時間が取れなかった。意欲でも手順でもなく時間が制約」と記録しています。AIは写真が届けば書きます。写真を撮って送る人がいなければ、何も始まりません。

AIで運用するアカウントの続き具合を決めていたのは、AIの稼働時間ではなく運用者の時間でした。

## 任せても止まったこと2：自発投稿だけでは、知らない人に届かなかった

自発投稿でいちばん多く表示された1本は176回でした。当時のフォロワーは約120人で、そのあたりで止まっています。リプライでいちばん多く表示された1本は2,153回でした。

7月の4週間は、自発投稿を1日も休んでいません。それでもフォロワーは週によって増えたり減ったりしました。

| 週 | リプライ数 | フォロワー |
|---|---:|---:|
| 7月6日〜12日 | 53件 | +8 |
| 7月13日〜19日 | 57件 | +12 |
| 7月20日〜26日 | 14件 | -3 |
| 7月27日〜31日（5日間） | 0件 | -1 |

写真の撮り方も文章の長さも変えていません。違っていたのはリプライの件数です。

言葉が返ってくる割合も違いました。4月4日から8月12日までの自発投稿167件のうち、リプライが付いたのは17件、約10%です。同じ期間にこちらから送った一言933件のうち、返信が返ってきたのは340件で、多く見積もって約36%でした。この36%には、こちらが同じスレッドに重ねた返信も混じっているので、上限として読んでください。

リプライは、相手の投稿の下に並びます。知らない人の前に出る入口は、リプライの側にありました。そしてリプライ先を選んで送る作業は、AIに任せていません。

## 任せても止まったこと3：数字は集まっていたのに、見ていなかった

数字を集めるのも、日曜の週次レポートも自動にしていました。毎週きちんと読んでいたのに、5月から7月にかけて伸びが鈍った理由が分かりませんでした。

レポート本体に出ていたのは、リプライの件数とフォロワーの純増だけでした。総インプレッションは、レポートの元データには5月から毎週入っていました。人が読む画面に転記していなかっただけです。私はその画面を17回見て、毎回「件数を戻す」と決めていました。

あとで総インプレッションの列を足すと、こう並びました。

| 時期 | リプライ数 | 総インプレッション | フォロワー |
|---|---:|---:|---:|
| 5月中旬の1週 | 58件 | 4,881 | +25 |
| 7月中旬の1週 | 60件 | 2,066 | +8 |

件数はほぼ同じで、結果は3倍以上違いました。件数だけの画面では、どちらも「目標達成」の行に並びます。

自動化すると、集める数字は増えます。どの数字を人の目の前に出すかは、自分で決めないかぎり、最初に作ったときのまま固まります。いまは週次レポートに、総インプレッション、100インプレッション以上の投稿の本数、新規フォロー、離脱を足しています。見方は [インプレッションやフォロワーが減ったときに見る4項目](/x-impressions-drop) に書きました。

## AIでXを運用するなら、最初に決めておくこと

この約6ヶ月から、始める前に決めておけばよかったことを3つ挙げます。

1. **守らせたい言葉の決まりを、数えられる形で書く。** 「避ける言葉の表」は、あとで本文を検索すれば効いたかどうか数えられます。「人間味を出す」のような方針は、そのままでは数えられませんでした
2. **運用者の時間を、止まる原因として先に見積もる。** 写真を撮る、リプライ先を選ぶ、週報を読む。自動化しても、この3つは人に残りました
3. **週報に、届いた量と入口・出口を最初から出す。** 件数とフォロワー純増だけだと、改善案は「件数を増やす」の1つしか出てきません

## この記録で分からないこと

- 1つのアカウントの観測で、他のアカウントで同じ結果になるかは分かりません
- おじいちゃんの口調が効いたのかは分かりません。標準語で送った場合と比べたことがありません
- 特定の投稿や施策が、フォロワーの増減を引き起こしたかは分かりません
- 返ってきたリプライの本文は保存できていないので、どんな会話だったかは書けません

## よくある質問

### 全部自動にできますか？

自発投稿は、写真を送ったあと自動で出ています。リプライは、相手を選ぶところと送るところを人がやっています。フォロワーの増減と関わりが大きかったのはリプライの件数だったので、ここを自動にしなかった分だけ、運用者の時間が残りました。

### 費用はどれくらいですか？

生成AIは無料枠で動かしています。X API は従量課金で、5ドルの上限を決めて自動チャージを切っています。

### AIが書いた投稿だと、読む人に分かりますか？

投稿の中で、人間の思い出や家族の話は作らせていません。AIのおじいちゃんが、実在するベランダの写真を見て書いている、という範囲から出ない決まりにしています。
