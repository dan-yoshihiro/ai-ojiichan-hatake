# AIにXの投稿をどこまで任せられるか：6ヶ月自動投稿して、人に残った3つの仕事と費用

*公開: 2026-10-02 / 最終更新: 2026-10-11 / 記録者: [@ojiichan_hatake](https://x.com/ojiichan_hatake) / 観測期間: 2026-04-04〜2026-10-11*

> **TL;DR:** AIにXの自動投稿を任せて、うまくいったのは言葉の決まりを守らせることでした。「元気な」を含む定型の投稿は、62%から6%に減っています。止まったのは人の側です。171日のうち投稿があったのは151日で、止まった週の自分のメモには「時間が取れなかった」とあります。いちばん多く表示された1本は私が手で送ったリプライでしたが、ふだんの1本は自発投稿のほうが届いていました。AIと自動処理に任せられたのは、書いて出すことと、数字を集めることまでです。費用は生成AIが無料枠の範囲、X API が月2ドルほどで、AIの定型返答がそのまま公開された事故が1回ありました。

AIに書かせれば、毎日の投稿は止まらない。始める前の私は、そう考えていました。

店や教室などの事業で、AIにSNSの投稿を任せて手間を減らしたい人、任せようか迷っている人に向けた記録です。導入の前に、何がAIに渡せて、何が自分の仕事として残るかを見積もる材料にしてください。

アカウントは「おじいちゃんの畑」で、AIに農家のおじいちゃんを演じさせています。畑は2階の南向きのベランダ、育てているのはミニトマトと小松菜です。運用しているのはエンジニアの私1人です。店や商品の宣伝用のアカウントではないので、売上や問い合わせへの効果はこの記録からは分かりません。

## 「AIだから毎日止まらない」と書いた日

2026年4月4日、フォロワー1人で始めました。最初の目標は「1ヶ月で100人」です。15日経った4月19日、フォロワーは10人でした。目標は、5月末までに50人へ下げました。

同じ4月19日に、アカウントの設計書を1本作っています。北極星として置いたのは、この1文です。

「AIなのに毎日失敗して、毎日学んで、毎日ベランダのミニトマト1鉢と向き合い続けるおじいちゃん農家」

1文のなかに「毎日」が3回出てきます。ほかのアカウントとの違いを並べたところには、軸の1つとして「AIだから毎日止まらない」とも書きました。

最初の投稿は、記録を始める前日の4月3日の夜に出しています。そこから9月20日までの171日のうち、自発投稿があったのは151日でした。

投稿が止まった週、私は自分用のメモにこう残しています。「時間が取れなかった。意欲でも手順でもなく時間が制約」。読み返すと、設計書の1行とメモの1行がちょうど向かい合っています。止まったのはAIが書く手前で、写真を撮ってLINEに送る私のところでした。

この記事は、AIに投稿を任せた約6ヶ月で、何がAIの側に移り、何が人の側に残ったかの記録です。残ったものは3つありました。写真を撮って送り続けることと、相手の投稿へ出向くことと、どの数字を見るかの判断です。フォロワーは9月27日に142人、10月11日には169人になっています。

## 写真を送ったあとは、人の手を通らない

止まった場所がどこにあるのかは、流れのなかで見たほうが分かりやすいので、先に仕組みを書いておきます。

ベランダで撮った写真をLINEに送ると、Make がそれを受け取ります。次に、Dify 上で動かしている Gemini 2.5 Flash が、作物ごとの栽培メモを参照して、おじいちゃんの口調で本文を書きます。栽培メモはミニトマト用と小松菜用の2つです。書けた本文はもう一度 Make を通って、本文と作物の区分に分けられます。最後に Google Apps Script がハッシュタグを付け、X API から投稿します。写真を送ったあと、ここまで人の手は入りません。

リプライは別の流れです。菜園アカウントの投稿を見て、送る相手を私が選びます。相手の投稿をAIに貼ると、口調を揃えた草案が2案出てきます。どちらかを選んで送るのも私です。

数字は毎日自動で記録していて、投稿ごとの数字とフォロワー数が溜まっていき、日曜にはそれをまとめた週次レポートが自動で出ます。

| 作業 | 担当 |
|---|---|
| 写真を撮ってLINEに送る | 私 |
| 自発投稿の本文を書き、Xに出す | AIと自動処理 |
| リプライの相手を選び、送る | 私 |
| リプライの草案を2案出す | AI |
| 数字の記録と週次レポート | 自動 |
| レポートを読んで来週の1手を決める | 私 |

全部を自動にできたわけではありません。人の手を通らずに回っているのは、自発投稿と数字の記録だけです。表で「私」が担当している3行が、このあと書く「人に残った3つ」にそのまま対応しています。

## AIに任せて効いたこと：言葉の決まりを表にする

人に残った話の前に、うまくいった側を書いておきます。

4月19日の設計書には、使う言葉と避ける言葉の表を入れました。避ける言葉には1つずつ、理由と代わりの書き方を添えています。実際の表から3行を抜き出すと、こういう形です。

| 避ける言葉 | 理由 | 代わりに |
|---|---|---|
| 「元気な〜じゃのう」の連発 | 4月14日〜18日の6件中5件で使っていて、単調になった | 冒頭は4種類の型（発見・日数・前日との比較・問いかけ）から選ぶ |
| 「完璧じゃ」「絶対〜」 | 言い切るほど、AIが書いた感じが強くなる | 「〜かもしれん」「わしの見立てじゃ」 |
| 「です」「ます」 | 標準語になると、おじいちゃんの口調が崩れる | 「〜じゃ」「〜のう」 |

禁止だけでは終わらせません。代わりに何を書くかまで、同じ1行に入れます。事業のアカウントなら、口調の代わりに、店でふだん使う言い回しや、使わないと決めている売り文句を、この3列の形で並べることになります。

表を作る前の自発投稿は32件で、そのうち20件に「元気な」が入っていました。62%です。作ったあと9月20日までの164件では、「元気な」を含む投稿は10件、6%でした。

表に書いた決まりは、あとから本文を検索すれば、守られたかどうかを数えられます。AIに任せてはっきり手応えがあったのは、この種類の仕事でした。

いいねも同じ2期間で、平均0.69から6.80に増えました。表のおかげかは分かりません。そのあいだに、フォロワーも増え続けていたからです。

## 人に残ったこと1：写真を撮って送る手が止まった

表の「私」の1行目、写真を撮ってLINEに送るところから止まりました。

月ごとに投稿のあった日を数えると、4月が27日、5月が30日、6月と7月も30日ずつです。8月は20日に落ち、9月は20日時点で14日でした。いちばん長く空いたのは3日で、8月7日から9日と、9月14日から16日の2回です。

5月から7月の3ヶ月は、ほぼ毎日出ていました。それがあるぶん、8月の20日と9月の14日が目立ちます。

自発投稿の流れで私の手が入るのは、最初の1段だけです。写真を撮って、LINEに送る。そこから先は、すべて自動にしてありました。手順を減らせるだけ減らしたので、人の手が要る場所は、私が写真を撮って送るかどうかの1か所しか残っていませんでした。

メモに書いた「意欲でも手順でもなく」は、その週の自分なりの切り分けでした。意欲が落ちたのでも、手順が面倒だったのでもない。残っていたのは時間でした。

ただ、記録を見直すと、このメモだけでは説明できない3日もあります。9月14日から16日は自発投稿が1本も出ていませんが、同じ3日間にリプライは26件送っていました。リプライを送る時間はあって、写真を撮って送る手は止まっていたことになります。止まる理由が時間だけとは限らないので、「時間を確保すれば続く」とまでは言えません。

AIは写真が届けば書きます。撮って送る人がいなければ、何も始まりません。

設計書の「AIだから毎日止まらない」は、流れのうちAIの段だけを見て書いた1行でした。北極星の1文に3回書いた「毎日」も、実際にかかっていたのはAIの毎日ではなく、写真を送る私の毎日です。

## 人に残ったこと2：相手の投稿へ出向く。ふだんは届かず、ときどき大きく届く

表の「私」の2行目は、リプライの相手を選んで送るところです。相手を選ぶのも送るのも私で、AIが出すのは草案の2案までです。

リプライは、ふだんは自発投稿より届かず、ときどき桁違いに届きました。表示回数の中央値は自発投稿の61.5回に対してリプライは12回ですが、2,000回を超えた2本はどちらもリプライです。相手の投稿の下に並ぶので、相手の投稿を見ている人の前にも出ます。

この一部の大きく届く1本は、相手を選んで送らないかぎり出てきません。人の手に残ったのは、送る作業そのものより、どの投稿へ出向くかを選ぶところでした。

週ごとの件数と届き方、フォロワーの動きは、[インプレッションやフォロワーが減ったとき、投稿を直す前に見る4項目](/x-impressions-drop)に書いています。

## 人に残ったこと3：数字は集まっていたのに、画面に出していなかった

表の「私」の3行目は、週次レポートを読んで来週の1手を決めるところです。

数字は毎日、自動で溜まっていました。けれど週次レポートの画面に出ていたのは、リプライの件数とフォロワーの純増だけです。インプレッションの数字は5月から毎週元データに入っていたのに、画面には転記していませんでした。

その画面を、私は17週見続けました。

件数と純増しか並んでいない画面から出てくる1手は、件数を増やすか減らすかだけです。

5月4日から10日の週はリプライ58件、7月6日から12日の週は60件で、件数はほとんど変わりません。その週に送ったリプライの表示回数の合計（以下、総露出）は4,881と2,066、フォロワーは+25と+8でした。件数と純増しか出ない画面では、この2週はどちらも「60件前後送った週」に見えます。

集める作業は自動にできても、どれを人の目の前に出すかは、私が決め直さないかぎり最初に作った形のままでした。いまは週次レポートに、総露出、100インプレッション以上の投稿の本数、新規フォロー、離脱を足しています。

## 書かせない決まりと、1回だけ起きた事故、かかっている費用

AIへの指示には、次の決まりを入れています。

- 農薬の濃度・量・希釈倍率は書かない
- 病気を言い切らず、「〜かもしれん」と書く
- 人間の思い出を作らない。祖父や父の話、幼いころの話は書かない
- 政治・宗教・差別的な表現は書かない

このうち機械でも確かめているのは、農薬の1つだけです。投稿の直前に、本文に「ml」「cc」「倍に薄めて」「希釈」が入っていないかを調べます。1つでも入っていればXには出さず、LINEへの返答だけを返します。残りの3つは、AIへの指示だけで守らせています。

決まりの外で、1回だけ事故がありました。8月22日、小松菜の種の袋を撮ってLINEに送ったときです。AIは袋の写真を畑の写真ではないと判断し、LINEで返すための定型文「わしは畑のことしかわからんのじゃ」を返しました。その文が、そのままXに投稿されています。表示は40回でした。

AIとしては、決めたとおりに動いています。抜けていたのは、LINEに返す文とXに出す文を、投稿の直前で区別していなかったことでした。9月10日からは、この定型文を含む本文はXに出さないようにしています。事業のアカウントで、商品の箱や伝票を撮って送ったときに同じことが起きると考えると、投稿の直前で止める仕組みは、AIへの指示とは別に要ります。

費用は、生成AIが無料枠の範囲です。X API は従量課金で、前払いした5ドルを上限にして、自動チャージは切っています。5月に確かめたときの消費は、月2ドルほどのペースでした。

## この記録で分からないこと

1つのアカウントを1人で回した約6ヶ月の記録です。ほかのアカウントで同じことが起きるかは分かりません。写真を撮って送る作業、リプライ、週報を読む作業に、それぞれ1日や1週で何分かかっていたかは記録していません。人に残った3つの仕事の重さは、時間ではなく、止まった日数と件数でしか示せていません。投稿日数やリプライの件数がフォロワーの増減を引き起こしたとまでは言えません。

## AIに投稿を任せる前に、私なら決めておく3つ

AIと自動処理に任せられたのは、書いて出すことと、数字を集めることまででした。書く手前で材料を渡し続けることと、書いたものをどこへ持っていくか、そして結果のどこを見るか。この3つは6ヶ月ずっと私の側にありました。事業で導入するなら、この3つを誰が、1日や1週のどこでやるかを先に決めておくことになります。

1つ目は、写真を撮って送る作業を、誰が1日のどこでやるかです。AIの稼働で「毎日」を約束しても、材料を渡す人が1日空ければ、その日は投稿がありません。

2つ目は、リプライを送る相手で決めることです。送ったリプライは4件に3件が20回以下しか表示されず、大きく届いたのは2,000回を超えた2本のような一部だけでした。5月4日〜10日の週と7月6日〜12日の週は、件数がほぼ同じ58件と60件でも、総露出は4,881と2,066でした。件数を揃えても、届き方は揃いません。出向く時間は、件数をこなすより先に、相手を選ぶことに使います。

その選び方も、手順に書いておきます。私は10月5日からの週に「以前に返した相手にも送る」と決めましたが、新しい相手を探す流れの中に、以前の相手へ戻る手順がありませんでした。1件も送れていません。

3つ目は、週報の画面に何を出すかです。集めるのは自動でも、出す欄を決めるのは人です。件数と純増だけの画面を作れば、私のように17週、同じ画面から同じ種類の1手しか出てこないことになります。

4月19日の私に1行だけ足させてもらえるなら、「AIだから毎日止まらない」のすぐ下に、「写真を送る私は止まる」と書かせます。自動化の設計図には、AIの段と一緒に、自分の段も書いておくべきでした。
