# AIでSNS運用はどこまで任せていい？ 人が残すべき判断

*公開: 2026-08-12*

> **TL;DR**: AIには、投稿案の作成・数値の整理・次の仮説づくりを任せられる。一方で、事実確認、健康や安全に関わる表現、公開の最終判断は人が残すべきである。この分担で、個人の作業を1日1〜2分まで減らしながら運用を続けた。

AIでSNSを運用することは、完全自動投稿と同義ではない。この実験では、AIを「考える作業を減らす補助者」とし、責任を伴う判断は人が持つ設計にしている。

## AIに任せたこと

- 写真や文脈からの投稿案づくり
- 日々の反応データの整理
- 反応が大きかった投稿の抽出
- 次週に試す投稿テーマや仮説の提案

人が毎回ゼロから考えなくても、過去の反応を踏まえた案を比較できる状態を作るのが目的である。

## 人が残したこと

- 数字、事実、出典の確認
- 健康や安全に関わる表現の判断
- 読者を傷つける可能性がある内容の除外
- 投稿するかどうか、どの表現にするかの最終決定

AIの文章は流暢でも、正しいとは限らない。特に栽培や健康に関わる発信では、断定を避け、確認できないことを確認できないまま出さないことを優先した。

## 1日1〜2分に減らせた理由

人が担う作業を「写真と文脈を渡す」「最後に確認する」に絞り、それ以外の整理・草案・週次の振り返りを仕組み化した。作業を減らすことと、判断を手放すことは別である。

この分担が、毎日15〜30分かかりがちなSNS運用を続ける土台になった。仕組みの全体像は [AIにSNS運用を任せる仕組み](/docs/system-overview.md)、人が残す原則は [人間が守るべき原則](/docs/principles.md) にまとめている。

## 導入前の確認項目

AI運用を始める前に、次を決めておく。

1. AIが提案してよい範囲
2. 人の確認が必須な内容
3. 投稿しない内容
4. 何を見て翌週の判断を変えるか

この線引きがないと、AIは便利な補助者ではなく、判断責任を曖昧にする存在になりやすい。
