# Xのフォロワーが増えない個人が、最初に見直す3つのこと

*公開: 2026-08-12*

> **TL;DR**: フォロワーが増えないとき、投稿時間やハッシュタグを先に増やす前に、①誰の悩みに答える投稿か、②新しい人に届く動線があるか、③プロフィールと投稿が受け皿になっているかを見直す。この順番は、1アカウントの1→100人の実測から整理した。

「毎日投稿しているのに増えない」という状態は、努力不足と決めつけなくてよい。小規模アカウントでは、自発投稿がフォロワー外へ届きにくく、投稿の質と露出の動線を分けて考える必要がある。

## 1. 投稿が「誰のどんな悩み」に答えているか

「今日も順調」「きれいに育った」といった観察だけの投稿は、読む人が自分ごとにしにくい。反対に、困りごと・失敗・変化を具体的に置くと、読む理由が生まれる。

最初に確認するのは、投稿を読んだ人が次のどちらを受け取れるかである。

- 自分にも同じ悩みがある
- 次に何を観察・判断すればよいかが分かる

本アカウントでも、悩み解決型・失敗開示型は観察だけの投稿より反応が出やすかった。型別の実測は [X の投稿はなぜ伸びないのか](/docs/craft-axes.md) を参照。

## 2. フォロワー外へ届く動線があるか

小規模アカウントでは、自発投稿だけで新しい人に届く機会は限られる。本アカウントでは、他者の投稿に価値を足すリプが、フォロワー外への露出の入口になった。

ただし、短い同意や件数だけを目的にしたリプは、読まれても次の関係につながらないことがある。相手の状況を読み、読んだ人にも役立つ視点を足すことが前提になる。

## 3. 流入を受け止める場所があるか

リプでプロフィールを見てもらっても、プロフィールと自発投稿に一貫性がなければ、フォローにはつながりにくい。新しい人が数秒で分かるように、次の3点を揃える。

- 何を発信しているアカウントか
- 誰のどんな悩みに役立つのか
- 続けて見ると何が得られるのか

このサイトでは、リプを「動線」、プロフィールと自発投稿を「受け皿」として捉えている。詳細は [100人前後で伸び悩む理由](/docs/x-algorithm-reverse-engineered.md) に記録している。

## まず1週間でやること

投稿を増やす前に、直近の投稿を10本だけ見返す。

1. 悩みや変化が具体的に書かれている投稿は何本か
2. フォロワー外へ届いたリプは何本か
3. プロフィールと直近投稿だけで、何を発信しているか伝わるか

この3点を記録してから、次の1週間では1つだけ変える。複数の施策を一度に変えると、何が効いたのか分からなくなる。
