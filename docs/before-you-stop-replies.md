# リプライがしんどいとき、やめる前に見るべき数字

*公開: 2026-08-12*

> **TL;DR**: リプライは件数だけを追うと消耗しやすい。やめるか判断する前に、①新しい人に届いたか、②保存・引用・会話が起きたか、③フォロワー増減と同じ週にどう動いたかを分けて見る。本アカウントでは、リプ数を大きく減らした週にフォロワーが純減した。

リプライは手間がかかる。だからこそ「疲れたからゼロにする」か「数を増やす」かの二択ではなく、何が返ってきているかを見て判断する。

## 1. 露出はあったか

リプは、相手の投稿を読んでいる人に届く可能性がある。まずは、自発投稿より大きなインプレッションが出たリプがあるかを見る。

ただし、露出だけでは価値を判断しない。多く見られても、読者に何も残らなければ継続する理由は弱い。

## 2. 行動につながったか

次に見るのは、いいね、保存、引用、返信などの反応である。相手の状況に合わせた具体的な視点や解決の入口があるリプは、単なる同意より行動につながりやすい。

本アカウントでは、露出が大きいリプと、保存・会話が起きるリプは必ずしも同じではなかった。両方を分けて記録することで、続けるべき型を選びやすくなる。

## 3. フォロワー増減と同じ週にどう動いたか

W28〜W31では、リプ53件で+8人、57件で+12人、14件で-3人、0件で-1人という変化が観測された。1アカウント・4週間の記録なので因果を断定はできないが、少なくとも「減らしても影響がない」とは言えない結果だった。

詳しい数値と前提は [リプ活動を止めるとフォロワーはどうなるのか](/docs/reply-activity-drives-growth.md) に公開している。

## しんどいときの縮め方

完全にやめる前に、次の順で負荷を下げる。

1. 反応が薄い型を減らす
2. 相手を絞り、具体的な悩みがある投稿だけに返す
3. 露出と保存・会話の両方が出た型を残す

量を守ることより、無理なく続けられる形で「価値を足せるリプ」を残すことが目的になる。
